MC World Explorer

完整解压后运行 MC World Explorer.exe。请保留 app 和 runtime 目录，无需另装 Java。
选择存档目录，在地图中浏览、定位，或选择区域生成独立三维预览。

三维操作：点击画面捕获鼠标；WASD 移动，Space/Shift 升降，Alt 切换捕获，Esc 释放鼠标。
资源与插件：选择资源、查看按 Mod 汇总的解析诊断，或管理自行安装的可信解析插件。
想给自己的整合包补解析规则？在「资源与插件 → 解析诊断」导出 JSON，再点「插件开发说明 → 复制全文」。把说明和诊断发给 DSH、Claude Code 或 Codex，填上便携版与实例目录，就可以请它用 JDK 21 构建插件 JAR。
在「资源与插件 → 插件」里安装可信 JAR，勾选并应用，再重新生成同一选区核对效果。新装插件默认停用。

程序只读存档，不启动 Minecraft。未知模型或颜色行为会明确降级，不保证所有 Mod 均能解析。
配置、缓存、日志和导出保存在程序目录，请放在可写位置。请勿直接从 ZIP 内运行。
二维显卡型号保存在便携配置中。主窗口核实已用上所选显卡后，MCWE 会在运行期间恢复 Windows 原有设置。恢复完成后强制结束也可直接移动目录。若核对失败，正常退出时会恢复；若在恢复前强制结束，可从原位置重开并正常退出一次。
开发者小声说 🤫 要是刚好在恢复前强退又删了便携目录，MCWE 在系统设置里唯一可能留下的小尾巴就是原 EXE 完整路径对应的显卡偏好，想连脚印也扫干净的话，可以到 HKCU\Software\Microsoft\DirectX\UserGpuPreferences 里只清理该路径的 SpecificAdapter 和 GpuPreference 字段 🧹。
三维预览支持在中文输入法下直接使用导航键。点击预览画面后即可用 WASD 移动。
独立插件进程不是权限沙箱，请仅安装可信插件。

文件名含 SNAPSHOT 的包为本地候选，不是正式发布版本。
