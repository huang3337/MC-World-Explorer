MC World Explorer

完整解压后运行 MC World Explorer.exe。请保留 app 和 runtime 目录，无需另装 Java。
选择存档目录，在地图中浏览、定位，或选择区域生成独立三维预览。

三维操作：点击画面捕获鼠标；WASD 移动，Space/Shift 升降，Alt 切换捕获，Esc 释放鼠标。
资源与插件：选择资源、查看按 Mod 汇总的解析诊断，或管理自行安装的可信解析插件。
应用不预装插件；安装默认停用。插件开发说明可在程序内离线查看。

程序只读存档，不启动 Minecraft。未知模型或颜色行为会明确降级，不保证所有 Mod 均能解析。
配置、缓存、日志和导出保存在程序目录，请放在可写位置。请勿直接从 ZIP 内运行。
独立插件进程不是权限沙箱，请仅安装可信插件。

文件名含 SNAPSHOT 的包为本地候选，不是正式发布版本。
项目与使用文档：https://github.com/huang3337/MC-World-Explorer
