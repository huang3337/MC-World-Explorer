# 界面设计规范

- **确认日期**：2026-10-25
- **状态**：开发者已认可 V0.7 地图优先设计及当前风格，后续界面默认沿用
- **适用范围**：Java 主线的世界浏览、查找、地点、预览、提示和设置界面

## 设计方向

以世界内容为视觉中心，使用浅色工作区、简洁分区、中文文案和明确的操作层级。后续新增功能融入现有风格，避免每个版本另建一套视觉语言。

当前实现以 `src/main/resources/css/styles.css`、`fxml/main.fxml` 和 `fxml/map-view.fxml` 为基础。数值可按可读性和实际显示缩放调整；本规范固定的是视觉及交互原则，不要求所有页面复制相同布局。

## 布局与层级

- 世界内容优先获得空间；浏览工作区默认展示地图。
- 左侧承担世界和来源导航，支持调整宽度与收起；顶部提供当前世界摘要和主要操作。
- 存档详情按需展开；图层、标记及维护操作分组呈现，避免全部控件常驻占用地图空间。
- 每个操作区域突出一个当前主要动作；三维选区与生成使用主动作样式。
- 低频维护操作进入“更多”，保留清楚名称和必要确认；不能为了简洁隐藏失败恢复入口。
- 新版世界查找可以增加搜索和信息密度，但须复用已有控件与状态样式；地点、资源和展示功能按各自路线进入。

## 颜色基准

| 用途 | 当前基准 |
|---|---|
| 工作区背景 | `#F4F6F8` |
| 面板、菜单、输入表面 | `#FFFFFF` |
| 主文本 | `#243140` |
| 次要说明 | `#647383` |
| 主动作、键盘焦点 | `#2365C7` |
| 主动作选中 | `#174C9A` |
| 轻选中背景 | `#EAF2FF` |
| 边界 | `#DCE2E9`、`#D7DFE9` |
| 错误提示 | 沿用 `.field-error` 的 `#B3261E` |

地图、三维及玩家/出生点/传送门标记保留各自内容颜色，不能为了主题统一改变其既有语义。选择、禁用、焦点、加载和失败须同时通过形状、文字或操作反馈表达，不只依赖颜色。

## 字体、间距与控件

- 中文优先，使用当前微软雅黑 UI / Segoe UI 字体体系；正文约 13 px，次要信息 12 px，辅助状态 11 px，世界标题约 20 px，分区标题约 14 px。
- 信息以短标题和简明说明呈现，技术细节放在需要时可展开的位置；未知、缺失、加载中和失败分别说明。
- 使用约 8/12/16 px 的间距层级，适度留白；控件约 5 px 圆角，菜单约 7 px 圆角。
- 复用现有按钮、输入、列表、菜单与焦点样式，轻量阴影只用于必要的覆盖层和浮层。
- 默认保持单一浅色主题；新增主题库、运行环境升级、主题切换及自绘控件需有明确需求和影响评估。

## 状态与交互

- 显示真实任务阶段、来源状态和完成条件；不能通过虚构进度或提前显示成功营造流畅感。
- 菜单展开、详情切换等界面操作保持轻量，不重新扫描世界或重建渲染管线。
- 长名称与来源路径提供可读取的完整信息；错误提示给出可执行的下一步。
- 长摘要优先省略，不能挤掉导航和主要按钮文字。长错误限制显示高度并保留全文提示，不能挤掉地图、取消或重试入口。
- 按需详情支持 Esc 关闭并返回合理焦点；仅在面板展开时拦截，保留地图和三维选区的既有 Esc 行为。
- 核心操作支持键盘焦点，900×600 下保持可达；系统缩放和长文本须按实际变更验证。
- 新布局必须有旧新入口对照，保证玩家导航、高度带、重试、导出、取消及缓存维护等能力可找到。

## 验收与演进

UI 设计和风格已认可。后续以这一基准渐进完善，真实场景测试发现的问题可以在同一风格内修正。

视觉认可、布局自动化、真实存档功能、性能、显示缩放和发布验收分别记录。保持当前 JavaFX 与独立 LWJGL 窗口边界；改变框架、模块结构或三维嵌入方式仍需单独评估。

决策背景见 [DECISION-014](decisions/DECISION-014.md)，当前阶段见 [CURRENT.md](progress/CURRENT.md)。

## 三维自由框选（2026-10-25 专项）

范围下拉框保留固定档并新增“自由框选”。左键拖动确定矩形，松开锁定，可直接再拖重画；右键拖动地图、滚轮缩放。拖动期间禁止滚轮改变选区起点，Esc 清除已锁定区域或退出选择；生成期间 Esc 取消任务。有效区域沿用蓝色，超限显示红色与明确边长/总数限制，并禁用生成按钮。底层请求必须再次检查同样的限制。

## 已加载三维区域（2026-10-25 专项）

地图右上保留“已加载区域 · 数量”入口，展开 256 px 的白色可收起浮层，蓝色重开操作沿用当前按钮风格；浮层不改变地图视口宽度。短列表按内容确定首选高度，长列表滚动，缩放控件避让浮层和阴影，底部会话容量说明保留两行可读空间。

卡片显示北朝上的地表俯视缩略图、区块宽深、X/Z 范围、未完整加载的区块数和“重新打开”。缩略图复用二维地图的地表取样、名称配色、两格像素聚合和高度阴影；只共用原始区块数据，不使用三维材料颜色或截图。灰色为等比留白，暗色为二维地图暂无数据，不伪装成当前洞穴高度图层。来源区域与档位限制须明确；当前档位不能打开时显示切换档位提示。

列表只承诺当前会话的有效三维缓存。淘汰或源文件变化后更新，重新打开仍校验 Region 签名；本轮不加入持久地点、重叠复用或新的缓存策略。键盘焦点在面板内时 Esc 收起并返回入口，地图焦点下保留既有 Esc 语义。

列表顶部提供“清空”，作用于当前世界/维度的当前列表；每张卡片右上角使用小叉号“×”删除，底部保留完整宽度的“重新打开”。叉号有悬停提示、键盘焦点边框与“删除此已加载区域”无障碍名称。删除移除条目、二维缩略图及对应三维内存缓存，不修改存档；已打开的三维窗口可继续查看，之后重开需要重新生成。生成任务进行中禁用删除，防止操作含义与旧请求混淆。二维磁盘瓦片缓存与三维会话内存缓存须在说明中区分，不能把后者描述为永久保存。
