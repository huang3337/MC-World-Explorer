# 界面设计约定

0.7.4 采用以下界面与交互约定，保持 JavaFX 主界面与独立 LWJGL 三维窗口。选区固定、蓝绿切换和取消重选已有人工验收记录；不同DPI和窗口尺寸的覆盖范围仍单独记录。

## 信息层级

地图是主工作区。左侧存档库用于选择世界，主工具栏保留维度、图层、定位、三维选区与“资源与插件”；“工具”收纳导出和缓存维护。避免重复按钮、逐行操作卡片及无必要的技术说明。

三维选区突出范围、生成和取消；状态独立一行；“性能与资源”默认折叠。旧功能不能因整理入口而丢失。主界面右上“关于”是全局入口，不依赖存档选择；页面只放产品说明、版本、作者、项目地址与许可；作者区使用48px圆形头像及GitHub/B站双行文字，头像不响应点击、不放大，支持滚动和复制，避免加入开发流水。

选区锁定后固定在世界区块坐标，随地图平移/缩放显示，不随鼠标改选；加载时蓝色，成功后绿色，失败保留蓝色可重试。加载中按钮为“取消生成”，其他锁定状态为“取消选区”；按钮和Esc均可解除锁定，再调整范围、档位或重新框选。切换世界/维度清除旧选区，单纯切图层或清理地图瓦片不解除锁定。

“资源与插件”分三页：

- 资源：显示当前来源与状态，完整路径和手动操作按需展开。
- 解析诊断：先按 Mod/命名空间汇总，再筛选原因、查看方块详情和资产来源。默认突出失败/降级，说明类记录可主动查看。
- 插件：可搜索紧凑列表，勾选形成草稿，点击应用才生效；所选项统一展示详情、更新和卸载。安装默认停用，关闭放弃未应用草稿。

诊断只代表最近一次生成选区，不能宣称整个 Mod 失败或支持。原始身份、Mod 归属和资产来源分开；未知、未确认和截断明确显示。切换输入、失败和取消不得留下旧结果。

## 三维操作与提示

点击捕获鼠标，WASD/Space/Shift 移动，Alt 切换捕获，Esc 先释放、再次关闭，O 环绕，R 复位。失焦或最小化释放输入，返回后明确点击恢复。移动限于已加载场景。

准星信息简短显示原始方块 ID、Mod、坐标和解析状态，目标使用 5 像素线框。长内容省略时保留完整诊断入口，不把拾取实现细节塞入用户提示。
