## 2026-09-27 逻辑修复与当时的待验收项

- **根因定位**：问题不在 `VoxelViewer.vue` 的相机变换。Rust 网格生成侧面时使用真实世界 Y（包含 `min_y`），而顶面和底面把 `dy` 当作世界 Y；只在 Y=0 的旧测试无法发现这一差异。
- **实际修改**：顶面和底面的固定高度改为 `min_y + dy`，与侧面使用同一世界高度；未改变可见面判定、网格批次或资源上限。
- **自动化证据**：新增正高度 Y=153 与负高度 Y=-64 的单方块测试，要求上下表面和四个侧面均落在同一高度区间。Rust workspace tests、fmt 和 Clippy 于 2026-09-27 通过。
- **剩余门禁**：尚未在开发者先前截图对应的真实选区及视角复验，不能仅凭合成测试断言该现场画面已经修复；本 Issue 保持活动。
