### ISSUE-BUILDMESH-001：后端未验证选区属于出生点 9×9

- **严重程度**：🟠 高
- **类别**：安全性
- **文件**：`src-tauri/src/commands/build_mesh.rs`
- **行号**：审查时约 33–40 行
- **状态**：已修复

**问题描述**：

**影响范围**：
网格 Command 输入校验与文件读取授权范围。

- **解决日期**：2026-09-07。
- **实际修改**：新增并接入中心 9×9 包含性验证，包含负坐标和 2×2 右/下边界检查。

### ISSUE-BUILDMESH-002：区块失败状态被静默丢弃

- **严重程度**：🟡 中
- **类别**：错误处理
- **文件**：`src-tauri/src/commands/build_mesh.rs`
- **行号**：审查时约 51–60 行
- **状态**：已修复

**问题描述**：
初版用 `if let Ok` 忽略 Chunk 解码错误，且 Region 缺失直接不留状态，核心无法区分 missing、unsupported 与 corrupt，也无法形成警告。

**问题分析**：
局部失败可以继续生成成功目标，但不能被当作无信息空气；取消仍必须立即终止整个任务。

**建议修改**：
把读取结果显式映射为 `ChunkFailure`，保存在邻域中；取消直接返回，其他局部失败交由核心聚合。

**影响范围**：
目标/halo 降级警告和 Task 8 metadata。

- **解决日期**：2026-09-07。
- **实际修改**：Command 显式区分 Missing、Unsupported、Corrupt，并保留取消传播。
- **验证证据**：核心部分目标、缺失 halo 与 fallback 聚合测试通过；全目标缺失返回受控失败而非空场景。
