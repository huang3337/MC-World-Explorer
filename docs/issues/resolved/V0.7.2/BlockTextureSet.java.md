### ISSUE-TEXTSET-001：状态收集的坏区块异常会中止整个选区

- **严重程度**：中
- **类别**：错误处理
- **文件**：src/main/java/com/mcworldexplorer/voxel/resource/BlockTextureSet.java
- **行号**：46–65
- **状态**：已修复

**问题描述**：N1 引入实际 blockState 扫描后，延迟发现的 palette 索引损坏会在网格准备之前抛出异常，使原本可部分成功的区域整场失败。

**当前代码（审查时快照）**：
```java
for (var section : result.chunk().sections()) {
    states.add(section.blockState(x, y, z)); // ChunkDecodeException 直接传播
}
```

**问题分析**：既有 VoxelSceneBuilder 按区块捕获并报告 CORRUPT；新增收集发生在它之前，不能破坏已有隔离边界。

**建议修改**：逐区块捕获解码失败，继续准备其他目标块；损坏状态仍交给网格阶段报告。

**影响范围**：启用资源时含损坏区块的有限三维区域。

- **解决日期**：2026-10-26。
- **实际修改**：收集阶段逐区块捕获 ChunkDecodeException，不捕获取消；网格阶段保持 CORRUPT 状态。
- **验证证据**：新增“正常块+palette 越界块”回归，正常块贴图与网格保留、坏块状态为 CORRUPT；全量无失败。

### ISSUE-TEXTSET-002：衍生面图像缺少单状态工作内存预算

- **严重程度**：中
- **类别**：资源管理
- **文件**：src/main/java/com/mcworldexplorer/voxel/resource/BlockTextureSet.java
- **行号**：118
- **状态**：已修复

**问题描述**：源 PNG 的解码预算不能约束每个元素面合成的临时图像；1024 面的大尺寸资源可能产生过高工作内存。

**当前代码（审查时快照）**：
```java
BufferedImage base=composite(image(archive,face.texture(),images),face.tintIndex(),null,-1);
```

**问题分析**：源 PNG 的解码预算不能约束每个元素面合成的临时图像；1024 面的大尺寸资源可能产生过高工作内存。

**建议修改**：准备前累计单状态派生图像字节，32 MiB 上限，超限作为该状态可见降级。

**影响范围**：V0.7.2 资源驱动模型准备与三维预览。

- **解决日期**：2026-10-26。
- **实际修改**：准备前累计单状态派生图像字节，32 MiB 上限，超限作为该状态可见降级。
- **验证证据**：新增 23 元素/256 像素纹理夹具触发 32 MiB 工作预算，只让大状态降级，后续小状态仍可贴图；源解码 64 MiB/总图集预算保持。

含水增量复查：固体与静态水面按不同材质分开合成，水面为 FLUID；仅液体面应用液柱拉伸，固体遮挡盒及单方块计数保持。由含水台阶与原生夹具覆盖。
