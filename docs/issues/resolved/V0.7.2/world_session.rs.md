### ISSUE-WORLDSESSION-001：便携目录重叠判断未统一 verbatim 路径且错误处理驱动器根

- **严重程度**：🟠 高
- **类别**：安全性
- **文件**：`src-tauri/src/world_session.rs`
- **状态**：已修复

**问题描述**：
初版直接比较小写路径字符串；普通 `C:\app` 与 `\\?\C:\app` 不相等，且父路径为 `C:\` 时会要求剩余字符串再次以反斜杠开头，导致重叠判断失败。

**问题分析**：
便携目录与世界目录不得互为祖先。Windows 同一路径的普通/verbatim 表示差异和驱动器根边界不能成为绕过条件。

**建议修改**：
比较前统一分隔符、大小写、verbatim drive/UNC 前缀，并单独处理已经以目录分隔符结尾的根路径。

**影响范围**：
世界候选与 EXE 便携数据根的重叠拒绝。

- **解决日期**：2026-09-07。
- **实际修改**：新增 Windows 可比路径规范化并修正根目录父子判断。
- **验证证据**：路径段边界、驱动器根、普通/verbatim 等价和候选/便携目录双向包含测试通过。

### ISSUE-WORLDSESSION-002：会话编号耗尽错误被误报为任务编号耗尽

- **严重程度**：🟢 低
- **类别**：错误契约
- **文件**：`src-tauri/src/world_session.rs`、`src-tauri/src/error.rs`
- **状态**：已修复

**问题描述**：
会话 `last_id` 溢出时初版返回 `TASK_ID_EXHAUSTED`，混淆世界会话与后台任务两套独立编号。

**问题分析**：
前端需要根据稳定错误分类判断重选世界还是任务重试，编号域不能复用错误码。

**建议修改**：
增加独立的 `SESSION_ID_EXHAUSTED`，且耗尽失败不得覆盖当前会话。

**影响范围**：
极端会话生命周期错误和前端错误映射。

- **解决日期**：2026-09-07。
- **实际修改**：新增会话编号耗尽错误码与固定中文消息。
- **验证证据**：无活动、外来/旧 ID、会话耗尽三种错误分类测试通过，耗尽后旧会话仍可访问。
