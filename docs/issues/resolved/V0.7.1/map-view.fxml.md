### ISSUE-MAPFXML-002：纹理加载入口的省略号造成截断误解

- **严重程度**：低
- **类别**：UI 健壮性
- **文件**：src/main/resources/fxml/map-view.fxml
- **行号**：62
- **状态**：已修复

**问题描述**：开发者反馈只有简化模式可选，另一项显示不完全。原版入口末尾直接写有省略号，容易被理解为菜单文字截断或不可用模式。

**当前代码（审查时快照）**：
```xml
<MenuItem text="选择 1.21.1 客户端 JAR…" onAction="#handleViewerTexture"/>
```

**问题分析**：在 150% UI 缩放下展开真实弹窗，渲染文字与源文案相同，宽/高均达到首选尺寸；未在该环境复现布局裁剪，但原始文案本身存在省略号。之前的工具栏测试没有展开纹理菜单，不能直接证明文字完整性。

**建议修改**：改用明确的完整加载操作文案，并对实际展开弹窗的文字和尺寸增加断言。

**影响范围**：三维工具栏资源选择入口；纹理解析/图集逻辑不变。

- **解决日期**：2026-10-25
- **实际修改**：文案改为“加载原版纹理（1.21.1）”，保留已有文件选择动作；WorkspaceLayoutTest 展开 PopupWindow，断言渲染文本未被省略、标签宽高满足首选值，并保存本地截图。
- **验证证据**：修复后回归与截图结果见 V0.7.1 当前反馈修复记录。


修复验证：95 套件 / 325 项（312 通过、13 跳过、0 失败/错误），展开菜单文字/尺寸断言与截图通过；本轮并验证实际验收 CMD 可见窗口启动。
