### ISSUE-WORKSPACETEST-001：临时目录清理早于后台瓦片写入结束

- **严重程度**：低
- **类别**：资源管理
- **文件**：src/test/java/com/mcworldexplorer/ui/WorkspaceLayoutTest.java
- **行号**：806
- **状态**：已修复

**问题描述**：自动定位专项回归时，部分布局测试结束后 JUnit 删除临时目录失败，仍有瓦片 PNG 写入正在结束。

**当前代码（审查时快照）**：
```java
finally { controller.shutdown(); /* 随即恢复应用配置根 */ }
task.get(60, TimeUnit.SECONDS);
```

**问题分析**：生产 scheduler.close 使用 shutdownNow 请求停止，但这不代表在途缓存写入已结束。原测试随后恢复配置根并清理 @TempDir，形成 DirectoryNotEmpty/FileSystemException 竞态。

**建议修改**：测试清理时等待 executor 完成，再恢复配置根；不要在 FX 线程或 scheduler 同步锁内等待，避免阻塞回调。

**影响范围**：测试设施的隔离与稳定性，不改变生产地图调度行为。

- **解决日期**：2026-10-26
- **实际修改**：测试捕获所用 executor，controller.shutdown 后在测试线程 awaitTermination（5 秒），随后恢复配置根；真实地图测试也等待资源定位完成再检查生成按钮。
- **验证证据**：全量 96 套件 / 337 项无失败，目录正常清理；自动/手动绑定额外专项通过。
