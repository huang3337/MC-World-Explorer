### ISSUE-MAPVIEW-003：缓存删除期间可能被新的地图任务重新写入

- **严重程度**：🟠 高
- **类别**：资源管理 / UI 健壮性
- **文件**：`src/main/java/com/mcworldexplorer/ui/MapViewerController.java`
- **行号**：462-500、575-578
- **状态**：已修复

**问题描述**：
缓存删除前会取消现有地图任务，但删除在后台执行期间，拖动、缩放或尺寸变化仍可能再次调用 `refreshTiles()`。

**当前代码（审查时快照）**：

```java
scheduler.cancelAll();
Task<WorldMapCacheCleaner.ClearResult> task = new Task<>() {
    @Override
    protected WorldMapCacheCleaner.ClearResult call() throws IOException {
        return cacheCleaner.clear(target);
    }
};
```

**问题分析**：
新的地图块任务可能在清理过程尚未结束时重新生成并写入同一缓存目录，导致“清理成功”后仍残留本次操作期间产生的文件，也会让删除结果统计失真。

**建议修改**：

```java
cacheMaintenanceInProgress = true;
// 删除任务完成后恢复，并统一刷新当前视口。
```

**影响范围**：
清理缓存期间发生拖动、缩放、窗口尺寸变化或维度操作的场景。

- **解决日期**：2026-07-30
- **实际修改**：增加缓存维护状态和操作编号。删除期间暂停新的视口请求；成功或失败后恢复请求。切换存档会使旧操作回调失效，避免更新错误世界。
- **验证证据**：缓存目标测试和 2026-07-30 干净完整测试通过；应用启动日志无新增异常。
