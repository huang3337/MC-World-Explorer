### ISSUE-MAPVIEW-001：玩家后台读取完成时可能访问不存在的当前维度

- **严重程度**：🟠 高
- **类别**：异步状态
- **文件**：`src/main/java/com/mcworldexplorer/ui/MapViewerController.java`
- **行号**：737-769
- **状态**：已修复

**问题描述**：
玩家数据后台任务成功或失败后会立即重建当前维度固定标记；存档没有可浏览维度时，当前维度仍为空。

**问题分析**：
异步完成回调晚于存档维度发现，不能假设界面一定已经激活维度。直接生成固定标记会触发空状态访问并中断玩家列表更新。

**实际修改**：
玩家列表始终按任务结果刷新，仅在当前维度存在时替换视口固定标记；同时保留存档身份和请求编号双重旧结果隔离。

**验证证据**：
控制器目标测试、完整自动化测试和 JavaFX 启动检查通过。

### ISSUE-MAPVIEW-002：手动切换维度可能误用旧玩家定位请求

- **严重程度**：🟡 中
- **类别**：UI 状态
- **文件**：`src/main/java/com/mcworldexplorer/ui/MapViewerController.java`
- **行号**：235-299、837-850
- **状态**：已修复

**问题描述**：
跨维度玩家定位会暂存目标，等待维度状态激活后再居中。如果用户在等待期间主动切换到其他维度，旧目标可能在以后被错误应用。

**问题分析**：
暂存定位属于一次性界面意图，只有紧接着激活相同目标维度时才有效，不能跨越用户后续选择继续保留。

**实际修改**：
选择维度时若暂存目标与新维度不一致，立即清除旧定位；目标维度成功激活后也立即消费并清除。

**验证证据**：
玩家导航目标的地表模式与默认缩放测试通过；完整自动化测试和 JavaFX 启动检查通过。
