### ISSUE-VIEWPORT-001：连续缩放动画会累积并重放旧关键帧

- **严重程度**：🟠 高
- **类别**：UI 健壮性
- **文件**：`src/main/java/com/mcworldexplorer/ui/MapViewport.java`
- **行号**：296-331
- **状态**：已修复

**问题描述**：
每次吸附动画只停止现有 `Timeline`，但没有清空旧关键帧。第二次及后续缩放会同时重放以前的相机变换，造成比例回跳和指针锚点漂移。

**问题分析**：
滚轮连续缩放会频繁创建吸附动画，关键帧累积会直接破坏用户要求的平滑体验，并随着操作次数增加。

**实际修改**：
每次构建新动画前清空关键帧和旧完成回调，再生成当前起点、目标档位和指针锚点对应的唯一动画。

**验证证据**：
缩放数学、控制器与调度目标测试通过；完整真实目录测试和 JavaFX 启动检查通过。

### ISSUE-VIEWPORT-002：空标记提示在缩放时显示为黑色小框

- **严重程度**：🟡 中
- **类别**：UI 健壮性
- **文件**：`src/main/java/com/mcworldexplorer/ui/MapViewport.java`
- **行号**：74-133、206-256、476-505
- **状态**：已修复

**问题描述**：
Canvas 全局安装的 `Tooltip` 在鼠标离开标记或缩放重绘期间仍可能以空文本显示，界面上会出现没有内容的黑色小框。

**问题分析**：
标记命中是 Canvas 内部绘制状态，JavaFX 无法通过节点边界判断 Tooltip 是否应显示。把 Tooltip 安装到整个 Canvas 会让空内容也进入默认显示流程。

**实际修改**：
移除 Canvas 全局 Tooltip 安装，只在鼠标命中可见标记时手动显示；空命中、拖动、缩放、离开、替换标记、重置和程序定位时统一关闭并清空提示。

**验证证据**：
增加空标记不生成提示文本的单元测试；完整测试和 JavaFX 启动检查通过，开发者人工界面验收通过。
