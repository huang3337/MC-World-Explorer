**问题描述**：详情展开后没有 Esc 关闭路径，键盘用户须重新找到关闭按钮。

**当前代码（审查时快照，非最新实现）**：

- **解决日期**：2026-10-25
- **实际修改**：主工作区增加条件式 Esc 事件过滤；关闭后焦点返回详情按钮；详情关闭时不消费事件。
