### ISSUE-FXML-005：长名称或来源路径使顶栏导航按钮被压缩，世界列表和存档详情文字被省略

- **严重程度**：中
- **类别**：UI 健壮性
- **文件**：src/main/resources/fxml/main.fxml
- **行号**：31、41（审查时位置）
- **状态**：已修复

**问题描述**：长名称或来源路径使顶栏导航按钮被压缩，世界列表和存档详情文字被省略。

**当前代码（审查时快照，非最新实现）**：
```xml
<Button fx:id="sidebarToggleButton" text="世界列表" mnemonicParsing="false" .../>
<ToggleButton fx:id="detailsToggleButton" text="存档详情" mnemonicParsing="false" .../>
```

**问题分析**：HBox 在长摘要参与布局时可把按钮压到其首选宽度以下，实际 900×600 真实样本快照出现按钮文字截断。

**建议修改**：导航与详情按钮以首选宽度作为最小宽度，由摘要承担省略。

**影响范围**：900×600 及长来源路径的主工作区。

- **解决日期**：2026-10-25
- **实际修改**：两个按钮均设置 minWidth="-Infinity"；摘要仍允许缩短并提供路径提示。
- **验证证据**：修复前长名称布局测试失败；修复后两个按钮宽度不小于首选宽度，真实样本及缩放检查通过。
