# DECISION-017：当前存档解析采用有限双布局兼容

- **状态**：已确认
- **确认日期**：2026-09-06
- **确认人**：项目开发者
- **适用范围**：`tauri-rewrite` 当前的 `level.dat`、Anvil Region 和区块方块状态读取

## 背景

只适配单个现代样本会使解析链路依赖偶然结构；一次实现全部历史格式和扩展压缩又会扩大当前迁移范围。当前兼容范围需要明确且失败语义稳定。

## 最终选择

- 支持现代根级 `sections[].block_states.palette/data` 布局。
- 支持较早的 `Level.Sections[].Palette/BlockStates` 布局。
- 保留方块名称与 Properties，不把不同状态的同名方块提前合并。
- 支持 Anvil 区块载荷的 GZIP、ZLIB 和未压缩三种常规类型。
- 旧式 `Blocks/Data`、外置 `.mcc`、LZ4 和未知压缩当前返回“不支持”，不得猜测、修复或解释为空区块。
- 缺失、损坏、不支持和取消保持独立分类；单个区块失败不得抹掉其他成功结果。

## 不可变边界

格式探测必须有固定候选集合与资源上限，所有输入仍通过只读 `WorldSource` 获取。当前兼容集合不代表对应 Minecraft 版本的全部语义均已支持，也不改变 Java 稳定行为作为最终迁移基线。

## 影响

后续扩大格式兼容范围时沿用相同领域模型和错误边界；新增压缩方式或历史布局必须明确纳入当前规格，不能静默回退。
