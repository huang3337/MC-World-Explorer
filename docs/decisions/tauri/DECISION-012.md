# DECISION-012：Windows 只读来源使用逐级目录句柄保护

- **状态**：已确认
- **确认日期**：2026-09-04
- **确认人**：项目开发者
- **适用范围**：`tauri-rewrite` 的 Windows `mcwe-core` 只读文件边界

## 背景

仅做路径规范化和根目录前缀检查，无法阻止检查与打开之间发生目录替换或重解析点回绕。

## 最终选择

- Windows 上由 `world_source` 逐级打开并校验目录句柄，在安全打开目标前保持必要的祖先句柄。
- 拒绝重解析点、父目录跳转、绝对相对路径、设备命名空间、备用数据流和有歧义的 Windows 文件名。
- 目标文件只读打开，对外只提供读取与定位能力，不暴露写入、元数据修改或原始句柄能力。
- 其他平台在没有等价保护前明确返回不支持，不降级为存在竞态的路径检查。

## 影响

保护期间可能拒绝与只读边界不兼容的写入、删除或重命名句柄，链接式世界或部分云同步路径也可能被拒绝。这一取舍用于维持可验证的只读边界，不代表运行中的 Minecraft 世界是一致快照。
