# DECISION-022：Tauri 重构默认继承 Java 稳定行为

- **状态**：已确认
- **确认日期**：2026-09-10
- **确认人**：项目开发者
- **适用范围**：`tauri-rewrite` 的全部 V0.7 决策、规格、实施与验收

## 背景

框架迁移的目标是重实现同一个产品。阶段性范围或当前代码不能在没有明确确认的情况下改变 Java 稳定版的默认值、回退顺序、错误分类和用户交互。

## 最终选择

- Java 已确认决策、稳定实现和验收结果构成 V0.7 的默认产品行为与性能基线。
- Tauri 可以改变技术实现或分阶段交付，但不能为了迁就当前实现降低最终对等目标。
- 若确需改变 Java 的用户可见行为或安全边界，必须先列明差异、理由、影响和验收方式，并获得开发者明确确认。
- 文档、代码和 Java 稳定行为发生冲突时，暂停依赖该冲突继续扩展，先完成对照与开发者选择。
- Minecraft 存档只读、中心回退、缺失/损坏/不支持分类、取消和资源释放等既有语义默认继续有效。

## 文档含义

正式决策和规格只表达当前有效结论，不保留已经被后续确认废止的旧方案。阶段性未实现必须如实标记为未完成，但不能写成对 Java 行为的永久替代。

## 影响

V0.7 的技术结构可以不同于 Java，但必须通过固定样本、自动化、真实只读存档和必要人工验收证明行为对等。发现旧版疑似缺陷时先建立 Issue，不直接改变迁移目标。
