# DECISION-014：关闭主窗口时协调释放资源并退出应用

- **状态**：已确认
- **确认日期**：2026-09-05
- **确认人**：项目开发者
- **适用范围**：`tauri-rewrite` 的 Tauri 应用生命周期

## 背景

唯一主窗口消失不能代替宿主进程正常退出；退出前必须释放后台任务、世界句柄和 WebView 数据目录保护。

## 最终选择

- 关闭标签为 `main` 的唯一主窗口代表退出 MC World Explorer。
- 所有退出来源共享同一套幂等协调边界：停止新业务、取消并收束后台任务、释放世界与 WebView 资源，然后正常退出。
- 不使用强制终止线程或进程代替资源析构。
- 关闭等待必须有明确上限，具体预算以真实负载验证为准。

## 影响

关闭是应用级资源协调过程，不能由前端组件卸载或窗口隐藏代替。关闭期间不再接受新业务请求。
