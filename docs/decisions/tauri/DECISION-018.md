# DECISION-018：由 Rust 核心生成简化三维渲染网格

- **状态**：已确认
- **确认日期**：2026-09-06
- **确认人**：项目开发者
- **适用范围**：`tauri-rewrite` 的有限范围简化三维生成与显示职责

## 背景

通过 IPC 发送完整体素并在前端生成网格会把领域算法和大量中间数据带入 WebView；为每个方块建立独立 Three.js 对象则会使对象数和 draw call 失控。

## 最终选择

- `mcwe-core` 根据目标体素和必要相邻数据完成可见面判断及确定性网格合并。
- 核心输出框架无关、可限制资源并可独立测试的网格结果，不依赖 Tauri 或 Three.js 类型。
- Tauri 应用层只协调任务、错误、身份和二进制序列化。
- Vue 与 Three.js 只负责把已验证结果建立为有限数量的 `BufferGeometry`，并管理相机、材质、场景替换和 GPU 资源释放。
- 目标区块失败、相邻数据降级和未知方块视觉回退保持不同语义。

## 不可变边界

相邻数据只用于边界判断，不得扩大目标几何范围。输出必须有明确资源上限；不能通过截断结果、每方块一个 Mesh 或把完整世界体素发送给前端规避限制。

## 影响

三维视觉范围可以在同一核心边界上扩展；若未来改用 GPU 体素、实例化或其他网格架构，需要重新确认重大技术方向。
