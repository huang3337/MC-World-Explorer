# DECISION-008：三维窗口采用环绕、有限平移和中心缩放交互

- **状态**：已确认
- **确认日期**：2026-08-14
- **确认人**：项目开发者
- **适用范围**：V0.6 及后续 Java 三维交互

## 背景

三维浏览既要保留未来左键选择入口，也要支持稳定观察地表、洞穴和区域边缘，不能把旋转中心永久固定或引入无边界自由飞行。

## 最终选择

- 左键使用 4 个逻辑像素阈值区分单击与拖动；拖动执行环绕旋转，单击事件保留给未来选择。
- 右键按屏幕空间有限平移相机与旋转中心，速度随视口、视场角和观察距离换算。
- 滚轮围绕当前旋转中心缩放；`R` 恢复中心、角度和距离，`Esc` 关闭窗口。
- 旋转方向采用开发者人工验收确认的模型拖动方向。

## 不可变边界

不加入自由飞行、无限平移、鼠标位置缩放或拖动期间持续拾取。未来拾取必须复用单击阈值，只在确认单击后执行。

## 影响

迁移版在没有另行确认的情况下应继承这套用户可见交互语义，即使底层窗口技术不同。
