# DECISION-001：采用严格便携的本地数据存储模式

- **状态**：已确认
- **确认日期**：2026-07-14
- **确认人**：项目开发者
- **适用范围**：V0.2 及后续版本

## 背景

便携版必须让用户能够明确知道应用数据位置，并可通过移除程序目录完成清理；把日志、缓存或配置写入 AppData 会破坏这一产品边界。

## 最终选择

- 应用生成的缓存、日志、导出和配置分别位于程序根目录的 `cache/`、`logs/`、`exports/` 和 `config/`。
- 开发运行以项目根目录为程序根；便携运行以 EXE 所在目录为程序根。
- 程序目录不可写时显示明确错误，不静默回退 AppData、注册表、工作目录或临时目录。
- 用户主动导出可以明确选择其他安全目录，但不得写入 Minecraft 世界目录。

## 不可变边界

Minecraft 存档始终只读；便携目录和世界目录不得重叠。应用不得自动删除旧版本留在系统目录中的用户数据。

## 影响

未来若增加安装版或改变数据位置，必须重新确认重大存储与发行边界；便携版约定不能被静默改变。
