# DECISION-009：内部 AI 计划文档不进入公开 Git 历史

- **状态**：已确认
- **确认日期**：2026-08-14
- **确认人**：项目开发者
- **适用范围**：正式分支、发布标签与本地开发资料

## 背景

`docs/superpowers/` 保存 AI 辅助设计和实施计划，具有本地开发价值，但不属于对外维护的项目状态文档。

## 最终选择

- `docs/superpowers/` 仅作为本地开发资料保留，并由 Git 忽略。
- 该目录不进入正式分支、发布标签或公开历史；正式文档不得依赖其存在才能解释当前项目状态。
- 项目目标、当前重大决策、技术契约、问题历史和里程碑概况分别写入对应正式文档层。

## 不可变边界

文档分层整理不得删除或缩减本地 Superpowers plans。它们可以保留详细过程，但不得被重复抄入 Decisions 或 Progress。

## 影响

基于旧历史的克隆可能需要重新同步；历史清理不得改变生产代码或已发布软件包内容。
