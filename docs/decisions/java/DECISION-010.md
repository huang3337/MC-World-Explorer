# DECISION-010：内部验证与打包工具不进入公开 Git 历史

- **状态**：已确认
- **确认日期**：2026-08-14
- **确认人**：项目开发者
- **适用范围**：正式分支、发布标签及本地工具目录

## 背景

本地试验打包、测量和验证工具只服务于开发验收；零散公开这些工具既不构成完整构建系统，也会混淆正式仓库边界。

## 最终选择

- `packaging/` 与 `scripts/` 默认保存本地打包、测量和验证工具，由 Git 忽略，不进入正式历史。
- 正式仓库只保留可编译源码、自动化测试、项目文档和必要构建基础。
- 本地产物、截图、报告、日志和验证清单必须在创建前确认已被忽略。

## 不可变边界

内部工具退出公开历史不代表可以缺少可复核的正式验证结论，也不得改变生产代码、发布附件或 Minecraft 存档。

## 影响

需要公开、可重复的正式打包流程时，必须另行确认其维护范围，而不能直接取消本地工具边界。
