# DECISION-004：二维浏览采用多级地图瓦片架构

- **状态**：已确认
- **确认日期**：2026-07-27
- **确认人**：项目开发者
- **适用范围**：V0.3 及后续二维地图浏览器

## 背景

固定中心图片不能支持任意区域拖动、指针缩放、坐标跳转、局部复用和按来源变化精确失效。

## 最终选择

- 地图使用固定 256×256 像素瓦片，并支持 1、2、4、8、16 方块每像素五个数据级别。
- 瓦片身份包含世界、维度、图层或高度范围、倍率、瓦片坐标和渲染版本。
- 当前视口和中心附近瓦片优先，使用两个有界后台 worker；可见区域进入终态后再预取外围一圈。
- 瓦片可以渐进显示；新倍率完成前保留旧画面，局部结果不进入终态缓存或导出。
- 运行期使用有限内存缓存，跨启动使用严格便携磁盘缓存，并按相关 Region 文件状态精确失效。
- 玩家、出生点和传送门使用独立覆盖层；玩家数据只读加载并保持在运行时。

## 不可变边界

所有地图读取保持只读；磁盘缓存不得写入存档或 AppData。拖动回旧区域应复用已有结果，缺失和失败不得混淆。

## 影响

后续二维能力建立在瓦片坐标与视口模型上，不重新引入重叠大图作为主要浏览架构。缓存生命周期发生长期变化时需重新确认。
