# DECISION-005：三维渲染采用 LWJGL/OpenGL

- **状态**：已确认
- **确认日期**：2026-08-01
- **确认人**：项目开发者
- **适用范围**：V0.4 及后续 Java 三维开发

## 背景

JavaFX 3D 与 LWJGL/OpenGL 已使用相同真实数据、网格和相机完成隔离对照，需要确定正式三维后端。

## 最终选择

- 后续 Java 三维管线使用 LWJGL/OpenGL 3.3 Core 和显式 GPU 资源管理。
- JavaFX 继续承担二维主界面，不因三维后端选择而替换整个 UI 技术栈。
- JavaFX 3D 原型只保留为验证证据，不继续承载正式功能。

## 原因与边界

同一验证环境中，LWJGL 的上传成本、P95 帧时和工作集优于 JavaFX 3D，并通过 Windows x64 打包、启动和释放验证。该结论不自动覆盖其他显卡或远程桌面环境；窗口、上下文、着色器和 GPU 资源必须显式释放。

## 影响

Java 版长期维护 LWJGL、GLFW、OpenGL 和平台原生库。未来改用其他三维后端需要重新确认重大架构。
