# DECISION-007：正式三维预览使用独立 LWJGL 窗口

- **状态**：已确认
- **确认日期**：2026-08-14
- **确认人**：项目开发者
- **适用范围**：V0.6 及后续 Java 三维预览

## 背景

JavaFX 与 GLFW 拥有不同事件循环和资源生命周期；首个正式三维入口需要在复用已验证 OpenGL 基础的同时保持二维稳定。

## 最终选择

- JavaFX 主窗口继续承载世界管理、二维地图和范围选择，三维场景显示在唯一独立 GLFW/LWJGL 窗口。
- 正式 `viewer` 层负责请求、任务、内存场景缓存和窗口生命周期；解析、网格和 GPU 资源保持在共享正式模块。
- 三维线程不直接访问 JavaFX 控件，状态通过明确接口切回 JavaFX 线程。
- 三维创建失败或窗口关闭不得破坏二维地图使用。

## 不可变边界

同一时间只维护一个正式三维窗口；创建、替换、关闭和异常路径必须释放 OpenGL、GLFW、线程及场景资源。

## 影响

如果未来从独立窗口改为嵌入式三维，需要重新确认界面、渲染和线程架构。
