# DECISION-002：Region 采用标准 Anvil 与可扩展分层设计

- **状态**：已确认
- **确认日期**：2026-07-14
- **确认人**：项目开发者
- **适用范围**：V0.2 及后续 Region 兼容扩展

## 背景

Region 容器、压缩和区块 NBT 结构具有不同的兼容范围与安全责任，不能耦合成一次性读取流程，也不能无边界声称支持全部历史或 Mod 格式。

## 最终选择

- Region 层负责标准 Anvil `.mca` 头、位置、时间戳、长度和只读负载读取。
- 压缩层独立处理 GZIP、ZLIB 和未压缩负载；NBT 层再按受支持布局解析 Section 与方块状态。
- LZ4、外置 `.mcc`、旧 `.mcr` 和未知容器或压缩必须明确报告不支持，不能解释为空区块。
- 缺失、损坏和不支持保持独立；单区块失败不得阻止其他区块处理。

## 不可变边界

所有偏移、长度和解压大小必须有上限；文件只读打开，不提供修复、写回、移动、删除或截断接口。新增格式应扩展对应层，不建立既有安全边界。

## 影响

后续 Region 兼容扩展必须明确增加格式、依赖和测试范围，不能用猜测性回退代替受支持契约。
