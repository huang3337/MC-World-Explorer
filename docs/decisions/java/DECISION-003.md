# DECISION-003：多维度预览采用统一图层系统

- **状态**：已确认
- **确认日期**：2026-07-18
- **确认人**：项目开发者
- **适用范围**：V0.2.1 及后续多维度二维预览

## 背景

主世界、下界、末地和 Mod 维度的垂直结构不同，但应共享预览、缓存和交互模型，不能为每个维度复制一套渲染流程。

## 最终选择

- 所有维度使用统一图层抽象，并支持地表总览和 32 格高度带。
- 地表总览寻找完整垂直范围内的最高可见地表；高度带在指定范围内寻找具有可通行空间的地面。
- 玩家位于目标维度且坐标可靠时可使用玩家高度；否则主世界、末地和未知 Mod 维度默认地表，下界默认包含 Y=64 的高度带。
- 图层按需生成，缓存按世界、维度、中心、图层、高度范围和渲染版本隔离。

## 不可变边界

不推测玩家在其他维度的历史位置，不按维度名称猜测 Mod 高度语义；所有读取保持只读，缓存遵守严格便携存储。

## 影响

新增维度应提供数据来源和默认图层规则，并复用统一图层与缓存模型。
