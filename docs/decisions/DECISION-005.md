# DECISION-005：V0.3 只同步源码，软件包与发布延后到 V0.3.1

- **状态**：已确认
- **确认日期**：2026-07-29
- **确认人**：项目开发者
- **适用版本**：V0.3、V0.3.1

## 决策背景

V0.3 已完成地图浏览器计划功能、自动化测试、真实存档只读验收、逐文件审查和人工界面验收。开发者认为当前功能已经足够，可以将源码同步到 GitHub，但希望在 V0.3.1 继续进行最后完善后，再考虑面向用户的软件包与正式发布。

该选择会影响版本状态、Gradle 版本、Git 提交范围、路线图和后续发布流程，因此作为已确认的重要开发与发布决策记录。

## 最终选择

- V0.3 源码版本定为 `0.3.0`。
- V0.3 完成文档同步后创建统一提交并推送到远端 `main`。
- V0.3 不构建 Windows 软件包。
- V0.3 不创建版本标签或 GitHub Release。
- 下一开发阶段为 V0.3.1，具体完善内容必须在开始前另行确认。
- V0.3.1 完成自动化、审查和人工验收后，再决定是否构建软件包、创建标签和发布 GitHub Release。
- V0.3.1 完成前不进入 V0.5。

## 影响

远端仓库会包含完整 V0.3 源码和验收记录，但现有可下载软件包仍保持 V0.2.1。源码版本完成与二进制软件包发布在本阶段明确分离，README 和路线图必须避免把 V0.3 描述为已经发布的软件包版本。
