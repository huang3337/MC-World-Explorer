# DECISION-011：内部 AI 设计文档退出公开 Git 历史

- **状态**：已确认
- **确认日期**：2026-08-14
- **确认人**：项目开发者
- **适用范围**：整个 Git 历史、正式分支与发布标签

## 决策背景

`docs/superpowers/` 保存 AI 辅助开发过程中形成的设计草稿和实施计划。这些文件对本地开发有参考价值，但不属于面向用户和外部开发者维护的正式项目文档，不应继续由公开仓库追踪。

该目录已经分散进入多个历史提交及发布标签。只在当前版本删除文件仍可从旧提交访问，不能满足退出公开仓库历史的要求。

## 备选方案

### A：仅从当前版本取消追踪

- 后续提交不再包含该目录。
- 旧提交和发布标签仍可访问全部历史文件。
- 不改变任何现有提交哈希。

### B：重写正式历史并保留本地文件

- 从 `main` 和全部发布标签的历史中移除 `docs/superpowers/`。
- 将 `docs/superpowers/` 加入 `.gitignore`，本地文件继续保留。
- 修正当前正式文档中指向该目录的引用。
- 受影响提交和标签获得新的 Git 哈希，需要强制更新远端。

## 最终选择

选择 **B：重写正式历史并保留本地文件**。

实施前必须建立完整仓库历史包、本地目录副本和逐文件 SHA-256 清单。重写及远端更新完成后，再次核对本地 19 个文件的内容与哈希，确保本地资料没有变化。
