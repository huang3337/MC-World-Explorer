# DECISION-024：0.7.4 纯本体交付边界

- 日期：2026-11-05；目标：分离Mod专用协议探索、延期代码及预装插件，保持本体源码与发行包的交付边界清晰。
- 执行计划：[V0.7.4](../progress/V0.7.4.md)。本决定覆盖旧的内置适配、SDK/插件同版本交付及代表插件验收路线。

## 本期选择

0.7.4 交付通用资源解析、工具本体和通用插件管理。安装、删除、启停与清理属于本体能力，不包含专用适配。

正式源码、构建任务和应用包仍不包含延期 Mod 专用适配、预装插件、SDK 生成器与示例。通用安装库、清单校验、隔离 worker、解析入口和设置界面属于本体。测试只生成临时验证插件，不安装到项目配置或交付包；旧专用协议和插件包继续留在仓库外。

安装默认停用且不执行插件；停用须退出 worker、移除规则并清除旧解析/场景缓存，仅保留可再次启用的安装副本与必要状态。卸载须删除受管理副本和状态，最后一个插件卸载后不遗留空索引或安装目录。删除被占用时须显示原因并可重试，不得静默算成功，不得删除用户选择的原始文件。独立进程不是操作系统权限沙箱。

延期开发材料移出 Git 工作树，后续版本重新立项后评估，不作为本期构建输入或验收门槛。旧实验包删除，不保留旧路线文档副本。既有正式历史版本不重写；原始本机测量证据不计入交付内容。

## 通用解析准入

1. 按公开资源格式及可核对的消费语义解析，不按特定 Mod 私有类、注册字段、方块名称硬编码。
2. 至少两个独立真实来源验证同一入口；同资源换 namespace 不算独立来源。两例成功不代表覆盖多数 Mod，未建立分母时不宣称广泛覆盖率。
3. 保留原始方块身份、资源来源、成功/有意空/降级/失败区分。未知 loader、颜色回调、缺资源或预算超限必须给出原因。
4. 来源完整内容指纹、资源顺序、输入变更检测、读取/几何/内存预算不因提速而取消。

当前本体保留标准 blockstate/JSON 模型、父链、元素、材质、变换与普通 OBJ。普通 OBJ 有 Create 与 Immersive Engineering 两个独立资源见证，但不等于整个 Mod 支持。composite/elements/empty/separate_transforms 的专用 loader 入口未准入；普通 JSON 的 elements 字段仍受支持。

原版标准颜色绑定、群系颜色、资源身份和基础模型数学仍有本体消费者，保留。为延期插件开发的 Mod/加载器类读取、动态注册恢复、资源生成、容器物品/实体及 Moonlight 服务退出本期。不能为了移除插件破坏已修复的普通颜色链路。

## 只读与架构边界

JavaFX 主界面＋独立 LWJGL 窗口，已加载场景内自由移动与 HUD；不做动态区块流送，不启动 Minecraft，不加载、初始化或执行游戏/Mod/加载器类，不修改实例和存档。当前所需客户端颜色协议仅把已选客户端类文件视为有界纯数据；允许读取纯数据不等于任意静态协议都应内置。

每次推进一个检查点；自动测试、真实保存数据、隐藏 GL、性能与原生人工验收分开记录。本期按该范围交付；提交与发布需完成对应的审查、测试和包核对。
