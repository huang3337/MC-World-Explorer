# DECISION-015：V0.7 收口并前移三维资源基础

- **状态**：已确认；V0.7 已收口，V0.7.1 按任务推进，实施状态见 CURRENT.md
- **确认日期**：2026-10-25
- **确认人**：项目开发者
- **适用范围**：V0.7 完成口径、V0.7.1 任务边界与后续优先级

## 背景与授权

开发者认可现有 UI 风格与交互，并授权完成自由框选、已加载区域列表、二维地图缩略图、删除/清空等配套优化。随后明确认为 UI 规范与这些功能改进的 V0.7 范围已完成，并同意先完成最终审查、回归和文档收口，再建立 V0.7.1 三维资源基础任务。

本次确认用于源码功能范围收口，不代表未执行的原生帧率、多样本、跨屏 DPI 或发布验证已经通过。既有测量与测试快照按原记录保留，缺失证据列为后续资源阶段基线及发布前验证项。

## 备选方案

1. 保持 DECISION-013 的顺序，先搜索和地点，之后再做原 V0.10 资源。
2. V0.7 收口后前移视觉资源，将完整立方体真实纹理链路限定为 V0.7.1，后续再细化模型与 Mod 兼容。
3. 继续把资源功能加入 V0.7，推迟界面阶段完成。

## 最终选择

采用方案 2。V0.7 冻结界面与已授权配套优化，收口源码标识为 0.7.0；V0.7.1 为下一阶段，目标为本地资源读取、有界纹理图集、明确支持的常见完整立方体贴图与朝向、可靠降级及资源释放验证。

原 V0.10 的基础资源链路前移至 V0.7.1；复杂模型、透明/裁剪/流体和 Mod 兼容保留为后续视觉阶段候选，按实测拆分后再确定 0.7.x 子版本。V0.8 世界查找、V0.9 地点回访暂缓，其他长期产品目标保留，不在本次重编号全部远期版本。

## 技术与验收边界

- 保留 Java 21、JavaFX、LWJGL/OpenGL、受控范围与独立窗口，不恢复 Tauri 探索、不做区块流送。
- 原有简化颜色模式继续可用。缺失或不支持资源有明确原因，不把“消除紫色”当作真实纹理/模型支持。
- 第一个验收版本以 Minecraft Java 1.21.1 的本地原版资源及固定建筑为基准，不承诺全部版本或 Mod 方块。
- 本地资源只读，不随项目分发游戏素材。资源路径、缓存与存档路径分离。
- V0.7 完成、源码版本号、提交、推送、打包、标签和发布分别记录。本次没有额外授权提交、推送或发布。
