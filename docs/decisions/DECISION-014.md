# DECISION-014：V0.7 采用地图优先的 JavaFX 浏览工作区

- **状态**：已确认；首轮界面已实现，开发者已认可 UI 设计与风格
- **确认日期**：2026-10-25
- **确认人**：项目开发者
- **适用范围**：V0.7 界面层级、详情呈现和既有功能入口整理

## 背景

开发者审阅了“地图优先”和“详情侧栏”两种交互原型，同意采用推荐的地图优先设计。原界面默认展示存档信息，地图与三维入口层级不足；本轮在已有 Java 主线上改善浏览体验。

## 备选方案

- 地图优先：地图始终作为主要内容，详情按需展开，减少常驻工具占用。
- 详情侧栏：同时展示地图和详情，信息更直接，但会持续挤占地图空间。

## 最终选择

采用地图优先布局。左侧保留可调整宽度及可收起的世界列表，顶部显示世界摘要，地图默认可见；详情按需覆盖展开，不触发地图容器缩窄和不必要的瓦片重排。

三维选择作为强调动作；坐标定位、玩家列表、图层和标记、导出与缓存维护分组呈现。图层完整高度范围、基础/增强性能档、受控范围和生成确认、进度、取消、重试仍沿用 V0.6 实际语义。

## 后续风格沿用

开发者于 2026-10-25 明确确认 UI 设计通过，后续开发可以接续此风格。浅色表面、地图内容优先、中文信息层级、蓝色主动作与按需面板成为后续界面基准，具体约定见 [界面设计规范](../UI_DESIGN_GUIDE.md)。该认可不自动替代真实存档、性能及版本整体完成确认。

## 影响与边界

- 使用现有 JavaFX 控件、FXML 与 CSS，不新增主题库、WebView 或运行时依赖。
- 不更换解析、调度、缓存、体素或 OpenGL 管线；独立 LWJGL 窗口和相机交互继续遵循 DECISION-009/010。
- 原型中的地图、坐标和进度为示例，正式界面必须连接现有真实状态；原型通过不代表 Java 实现已通过。
- V0.7 不提前实现搜索、地点持久化、纹理模型或动态流送。
- 布局实现后需检查 FXML 绑定、窄窗口可达性、既有功能回归及人工桌面体验。版本完成、提交、推送和发布仍分别确认。
