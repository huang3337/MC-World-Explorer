# V0.3 多人玩家标记实施计划

## 状态

- **计划日期**：2026-07-29
- **设计依据**：`docs/superpowers/specs/2026-07-29-v0.3-multiplayer-markers-design.md`
- **执行状态**：源码、自动化测试、真实存档只读验证、Rule 16 审查和开发者人工界面验收已完成
- **提交限制**：遵守 Rule 18，不提交、不推送、不打包

## 任务 1：多人玩家数据

- 新增不可变玩家位置模型。
- 新增 `playerdata/*.dat` 只读解析器。
- 增加名称缓存解析、短 UUID 回退和固定范围路径查找。
- 对损坏文件、缺少字段和非法数值逐文件隔离。
- 增加数据模型、NBT 和名称解析测试。

## 任务 2：玩家标记与菜单

- 选择世界后在后台加载玩家集合。
- 有有效多人数据时替换单个 `level.dat` 玩家标记；否则兼容回退。
- 在工具栏“玩家”开关旁增加玩家列表菜单。
- 条目显示名称和维度，处理重复名称与不可用维度。
- 增加菜单模型测试。

## 任务 3：跨维度玩家定位

- 增加待执行玩家导航状态，覆盖异步维度高度解析。
- 点击玩家后切换目标维度。
- 强制使用地表总览、`2 方块/像素` 和玩家 X/Z 中心。
- 保持“重置视图”仍返回维度原有默认中心。
- 增加导航目标和视口状态测试。

## 任务 4：Tooltip 缺陷修复

- 移除永久安装的空 Tooltip。
- 仅在命中标记时显示。
- 未命中、离开、拖动和上下文切换时隐藏。
- 增加可测试的提示判定边界。

## 任务 5：验证与收尾

- 运行目标测试和完整测试。
- 使用真实“刀剑”存档验证四名玩家、名称和维度。
- 比较 `level.dat`、全部 `playerdata` 的大小、修改时间和 SHA-256。
- 启动 JavaFX 检查 FXML、CSS 和运行时日志。
- 按 Rule 16 审查新增或修改生产文件。
- 同步 V0.3 进度、路线图和问题索引。
- 保留工作区变更，不创建提交、标签、软件包或 GitHub 操作。
