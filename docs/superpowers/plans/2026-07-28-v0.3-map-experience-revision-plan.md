# V0.3 地图体验修订实施计划

## 状态

- **计划日期**：2026-07-28
- **设计依据**：`docs/superpowers/specs/2026-07-28-v0.3-map-experience-revision-design.md`
- **执行状态**：源码实现、自动化测试、真实目录只读测试、启动检查、Rule 16 审查和开发者人工界面验收已完成
- **提交限制**：遵守 Rule 18，不提交、不推送、不打包

## 任务 1：默认图层与标记颜色

- 地图首次打开和首次切换维度固定请求地表总览。
- 保留默认中心和本次运行中的维度图层恢复。
- 提取共享标记颜色定义。
- 三个开关增加同色圆点、选中浅色背景和未选中灰化状态。
- 增加默认图层和颜色一致性测试。

## 任务 2：连续视觉相机

- 在离散 `MapZoomLevel` 外增加连续视觉方块/像素比例。
- 实现滚轮连续缩放、指针锚点、范围限制和最近五级吸附。
- 缩放按钮使用相同相机变换。
- 增加纯数学测试。

## 任务 3：旧图块保留与目标覆盖

- `MapViewport` 分离目标图块和旧级别底图。
- 任意级别图块按世界边界和视觉比例绘制。
- 目标视口完整覆盖前保留旧底图，完成后释放。
- 状态栏区分临时画面、补全和清晰完成。
- 导出只在目标完整图块就绪时允许。

## 任务 4：渐进图块生成

- 图块内部按关注点中心优先读取区块。
- 扩展生成监视器，按时间和新增像素发布局部快照。
- 局部快照只进入当前视口，不进入 LRU、磁盘缓存或导出。
- 取消和上下文请求编号同时隔离局部与最终结果。

## 任务 5：Region 与调度优化

- 预先计算图块覆盖 Region，缺失 Region 整批跳过。
- 已有 Region 在单图块任务中只打开一次。
- 首轮仅请求实际可见图块。
- 可见画面开始稳定后再提交低优先级预取圈。
- 并发上限保持两个。

## 任务 6：验证与收尾

- 运行地图目标测试和完整测试。
- 启用真实目录，验证首屏渐进时间和四类维度。
- 比较实际读取 Region 的大小、修改时间和 SHA-256。
- 实际启动 JavaFX，检查 FXML 和日志。
- 按 Rule 16 审查新增或修改生产文件并同步 V0.3 进度。
- 保留工作区变更，不创建提交、标签、软件包或 GitHub 操作。
