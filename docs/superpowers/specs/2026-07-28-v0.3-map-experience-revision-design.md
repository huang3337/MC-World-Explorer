# V0.3 地图初始图层、标记图例与丝滑缩放体验修订设计

## 状态与依据

- **确认日期**：2026-07-28
- **确认人**：项目开发者
- **适用范围**：V0.3 地图浏览器完成前的体验修订
- **上位设计**：`2026-07-27-v0.3-map-browser-design.md`
- **重大决策**：`docs/decisions/DECISION-004.md`

本修订解决开发者人工体验检查中确认的三项问题：

1. 打开存档时默认进入玩家所在高度带，而不是地表总览。
2. 玩家、出生点和传送门开关缺少与地图标记一致的颜色示例。
3. 未缓存区域加载较慢，缩放时立即清空旧图块并跳级，缺少类似 Xaero's Map 的连续感。

## 已确认目标

- 打开存档和首次切换维度时默认显示地表总览。
- 标记开关同时作为颜色图例，玩家为绿色、出生点为黄色、传送门为紫色。
- 滚轮期间连续缩放现有画面，停止后吸附到最近的五级缓存。
- 目标级别图块完成前继续显示上一缩放级别的地图。
- 进入未缓存区域后，目标约一秒内先显示中心附近的可辨认地形。
- 保留 `1、2、4、8、16 方块/像素` 五级磁盘缓存、Region 精确失效和存档只读边界。

## 默认图层

`MapViewerController` 首次建立维度状态时明确请求
`PreviewLayer.surfaceOverview()`，不再把玩家 Y 或下界 Y=64 规则用于地图初始图层。

默认中心规则不变：

- 主世界继续使用个人重生点、世界出生点和原点回退。
- 非主世界中，玩家位于该维度且坐标可靠时继续以玩家位置为中心。
- 其他情况继续回退维度原点。

用户主动操作高度滑块后切换到对应 32 格高度带。同一存档的同一维度在本次运行中继续恢复最后成功选择的图层和滑块位置；重新选择另一个存档时重新从地表总览开始。

## 标记开关与图例

三类标记继续使用现有地图颜色：

- 玩家：绿色 `#44c767`
- 世界出生点：黄色 `#f2c94c`
- 下界传送门：紫色 `#bd5cff`

每个开关包含一个同色圆点和文字。开启时显示对应颜色的浅色背景和边框；关闭时圆点、文字、背景和边框统一灰化。地图标记和开关必须从同一个颜色定义取得值，避免后续颜色漂移。

不开启新的独立图例面板，不增加说明卡片。开关本身承担图例和显示控制两种职责。

## 连续视觉缩放

### 双层缩放状态

地图相机同时保存：

- **视觉比例**：滚轮期间连续变化的 `double` 方块/像素值。
- **目标缓存级别**：仅允许 `1、2、4、8、16` 的 `MapZoomLevel`。

滚轮根据输入增量连续改变视觉比例，并保持鼠标指针对应的世界坐标不动。视觉比例限制在 `1..16`，不产生范围外画面。

滚轮停止约 `150ms` 后，按对数距离吸附到最近的五级缓存比例。缩放按钮使用同一相机变换，但直接过渡到相邻级别；重置视图恢复维度默认中心、默认缩放和视觉比例。

### 旧图块保留

`MapViewport` 分别维护：

- 当前目标级别图块。
- 上一个已经可见的级别图块，作为临时底图。

任意级别图块都按世界边界和当前视觉比例绘制，因此旧级别图块可以在连续缩放期间保持正确位置。吸附后不再清空画面；目标图块完成一块就覆盖一块。目标视口已经获得完整覆盖后释放旧底图。

临时拉伸只影响当前内存画面，不生成任意倍率 PNG，也不改变磁盘缓存身份。

## 渐进图块生成

### 中心优先

首轮只调度实际可见图块，不立即提交外围预取圈。图块按距离视口中心排序，中心图块优先。

单个图块内部的区块也按距离图块关注点从近到远读取。生成器约每 `100ms` 发布一次局部快照；如果在该时间内没有新增有效像素，则不发布重复快照。

### 局部快照边界

局部快照：

- 只进入当前请求的内存画面。
- 不加入 128 项完整图块 LRU。
- 不写 PNG 或元数据。
- 不被视为导出就绪。
- 请求取消或上下文变化后立即丢弃。

完整图块成功后才进入既有内存缓存，并通过原子替换写入磁盘缓存。

### Region 访问优化

生成前计算图块覆盖的 Region 集合：

- 缺失 Region 整批跳过，不再为其中每个区块重复执行文件存在检查。
- 存在的 Region 在当前图块任务中只打开一次。
- Region 内只读取地图块实际覆盖的区块。
- Region 来源状态仍在完整缓存写入和复用时校验。

实际可见区域开始稳定显示后，调度器才以低于可见图块的优先级提交一圈预取图块。后台并发上限继续为两个，避免多个 Region 解压任务争抢磁盘和 CPU。

## 状态与导出

状态栏区分：

- `临时缩放画面`：正在连续缩放或显示旧级别底图。
- `正在补全`：目标级别图块或局部快照尚未全部完成。
- `已清晰加载`：目标视口所有完整图块就绪。

只有第三种状态允许导出。导出仍使用目标级别完整图块和当前开启的标记，不使用临时拉伸画面或局部快照。

## 取消与错误

- 世界、维度、图层或目标缓存级别变化时，请求编号同时隔离局部快照和最终图块。
- 已开始任务继续响应取消检查；取消后不得写入磁盘缓存。
- 目标图块失败时保留可用旧底图并显示局部失败，不把整个视口清空。
- 旧底图不存在时继续使用稳定深色占位。
- 渐进发布失败只影响当前临时画面，完整图块生成仍可继续；完整生成失败按既有单块错误处理。

## 测试与验收

### 自动化

- 新存档和首次切换维度默认请求地表总览。
- 本次运行中主动选择的高度带按维度恢复。
- 三类开关颜色与地图标记颜色来自同一来源，关闭状态灰化。
- 连续视觉比例边界、指针锚点和五级吸附。
- 缩放期间保留旧图块，目标图块按世界坐标覆盖，完整覆盖后释放旧底图。
- 可见图块优先于预取图块。
- 图块内部中心优先，局部快照受时间和新增像素约束。
- 局部快照不进入完整缓存、不允许导出，取消后不发布也不写磁盘。
- Region 缺失批量跳过、存在 Region 单任务只打开一次。
- 原有缓存精确失效、标记、清理、导出和存档只读测试保持通过。

### 真实存档与人工验收

- 未缓存默认中心目标约一秒内出现可辨认地形。
- 连续滚轮时画面不变空，指针下世界位置保持稳定。
- 停止滚轮后目标图块逐块变清晰，不出现明显跳位。
- 快速连续缩放、拖动、切换维度和图层时没有旧结果回写。
- 主世界、下界、末地和 Mod 维度继续保持只读。
- 三色开关无需额外说明即可识别地图标记类型。

## 实施边界

- 不改为任意倍率磁盘缓存。
- 不重建完整多级图像金字塔。
- 不提高两个后台生成任务的并发上限。
- 不预扫描整个维度或全世界。
- 不读取 Mod 资源包。
- 不提交、不推送、不打包，直到开发者完成人工验收并明确确认 V0.3 完成。
