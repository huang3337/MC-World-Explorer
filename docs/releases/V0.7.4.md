# 0.7.4 发布说明

版本：0.7.4 · 日期：2026-11-05 · Windows x64 便携版 · 零预装插件。

## 新增与改进

- 全局“关于”页面提供工具说明、真实版本、作者、项目主页和复制信息。
- 更新应用图标及README实际预览截图。
- 三维选区在加载过程中固定为蓝框，成功后原位变绿；通过取消解除锁定后重新选择。
- 三维自由视角：WASD 移动、鼠标转向、上下移动、Alt 切换捕获/释放；Esc 先释放，已释放时关闭窗口，失焦自动释放输入。
- 准星目标信息与加粗选中线框，显示原始方块 ID、所属 Mod、坐标和解析状态。
- 资源、解析诊断、插件分为独立页面；按 Mod 查看当前选区的问题，复制或导出完整报告。
- 改善标准资源解析、颜色处理与场景重开，保留来源校验和明确降级。
- 通用插件安装、启停、更新和卸载，以及随应用提供的离线开发说明。应用零预装插件。

## 范围与限制

只读 Minecraft Java 版存档，保留二维地图与独立三维窗口；自由移动仅限已加载场景。通用格式解析不等于完整支持全部 Mod。专用适配不随本体发布，未知模型、资源或颜色行为会说明原因。插件独立进程不是权限沙箱。

性能因选区、资源与硬件而异。本次不承诺所有场景达到固定秒数，也不把旧数据作为当前发行包的新实测。

预览读取已保存到磁盘的内容，不实时同步游戏中的变化；刷新方式见[常见问题](../FAQ.md)。

## 获取与升级

从仓库 [V0.7.4 Release](https://github.com/huang3337/MC-World-Explorer/releases/tag/v0.7.4) 下载 Windows x64 ZIP，完整解压后运行 EXE，无需另装 Java。请勿覆盖正在运行的目录；应用设置与缓存位于便携目录。

版本标签为 `v0.7.4`，Windows 包附带同名 `.sha256` 校验文件。
