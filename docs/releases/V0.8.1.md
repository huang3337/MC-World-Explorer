# 0.8.1 版本说明

## 无 UI 开发者 SDK 与双模块架构（0.8.1）

- **物理拆分无 UI 核心库（`:mc-world-explorer-sdk`）**：将只读存档解析、二维地图采样与三维体素网格生成物理拆分为纯 Java 21 核心模块，零 JavaFX、Ikonli 与 LWJGL/OpenGL 依赖；桌面客户端直接依赖同一核心模块实现单源同步演进（关联 [GitHub Issue #1](https://github.com/huang3337/MC-World-Explorer/issues/1)）。
- **高层只读门面与三维 OBJ / 二维 PNG 导出（`com.mcworldexplorer.sdk`）**：提供 `WorldExplorerSdk`、`McWorld`、`SceneBuildRequest`、`MapRenderRequest` 与 `WavefrontObjExporter`。支持在无原版客户端 JAR 的环境中直接读取存档并导出纯色标准 Wavefront `.obj` + `.mtl`；传入对应客户端 JAR（及可选整合包实例目录）后，可将逐顶点群系着色与高分辨率/旋转双层遮罩按 Porter-Duff `source-over` 烘焙生成 `.obj` + `.mtl` + `_atlas.png`（自动翻转 OBJ `vt` 纵向纹理坐标），同时支持无头二维俯视 PNG 地图渲染导出，全程严格只读且不写磁盘缓存。
- **JitPack 与独立 SDK 构件分发**：本次发行除桌面端 Windows x64 便携包外，同步附带 `mc-world-explorer-sdk-0.8.1.jar`、`mc-world-explorer-sdk-0.8.1-sources.jar` 与 `mc-world-explorer-sdk-0.8.1-javadoc.jar`，并支持通过 JitPack 在 Gradle 或 Maven 工程中按版本标签直接引入。依赖坐标与完整调用示例见 [SDK 使用指南](../SDK_GUIDE.md)。

## 自 0.7.9 以来的三维群系着色与遮罩管线升级（0.8.0）

- **GPU 顶点群系着色与图集去染色化**：将三维预览的群系草色、叶色与水色从 CPU 逐色阶预烘焙贴图升级为 GPU 顶点属性实时相乘，基础贴图在 `TextureAtlas` 中仅保留单份拷贝，并将图集上限扩容至 `2048` 张贴图 / `4096 × 4096` 像素，消除 `16 × 16` 区块多群系过渡带因色阶贴图膨胀触发的图集超限简化颜色降级。
- **共面双层遮罩单次绘制合成**：针对草方块侧边（`grass_block_side` + `grass_block_side_overlay`）及 Forge / NeoForge `composite` 跨 `render_type` 共面双层模型，在片元着色器内按遮罩 Alpha 执行单次 Porter-Duff `source-over` 混合与法线方向受光计算，消除共面双四边形引发的深度闪烁（Z-fighting）与半透明排序伪影。
- **群系着色诊断细化**：区分缺少群系着色绑定的 `UNBOUND_TINT` 与已绑定但采样上下文异常的 `TINT_UNRESOLVED`，修复无染色方块的误报记录。

## 使用说明与已知边界

- **桌面端便携包**：`MC-World-Explorer-0.8.1-windows-x64.zip` 自带 Java 21 运行时，完整解压到普通可写文件夹后双击 `MC World Explorer.exe` 即可运行。升级自旧版便携包时，建议将新版 ZIP 解压到新文件夹并保留旧目录，首次打开新版或通过「设置 → 常用 → 从旧版目录导入数据…」即可只读导入旧版设置、地点标记、已装插件与地图缓存。
- **开发者 SDK**：需要 JDK 21 及以上环境，采用与主仓库一致的 GNU GPL v3.0 许可证。引入方式、默认选区/像素安全上限与示例代码见 [SDK 使用指南](../SDK_GUIDE.md)。
- 游戏外静态解析不启动 Minecraft、不执行游戏或 Mod 字节码；自定义实体渲染器与未知运行时动态模型限制见 [资源解析范围](../MODEL_PROTOCOL_CAPABILITIES.md)。
- 版本号、包指纹与验证记录见 [当前状态](../progress/CURRENT.md) 与 [0.8.1 验证记录](../progress/V0.8.1.md)。
