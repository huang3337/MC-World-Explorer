# 0.7.9 版本说明

## 检查更新、模态卡片与旧版数据迁移

- **双源只读检查更新**：新增国内镜像仓（Gitee 直连优先）与 GitHub 仓库双源更新检查。程序启动时默认后台静默检查（12 小时冷却，可在「设置 → 常用」关闭），发现未忽略的新正式版时不弹打扰窗口，仅在顶栏「关于」按钮右上角显示小蓝点；离线或超时保持静默。
- **常驻最新 Release 入口**：「关于」界面常驻提供直达最新发行版的 Gitee 国内镜像与 GitHub 链接（软件内不解析或展示网盘链接）；手动点击「检查更新」发现新版本时，在预留区域展开醒目提示指引前往下载新版便携包 ZIP，关闭界面后自动收起。点击仓库链接前会展示个人数据与缓存保留说明，确认后再由默认浏览器打开。
- **统一软件内模态遮罩与细节修复**：「关于」卡片、跳转前保留提示与新包首启导入卡片统一采用主窗口内居中模态遮罩呈现，不再弹出额外系统子窗口；消除点击「关于」卡片空白处残留蓝色焦点外框的问题，并新增作者 B站主页超链接。
- **一键导入旧版数据**：全新解压的便携包首次启动时自动弹出「导入旧版数据」卡片，也可随时在「设置 → 常用 → 从旧版目录导入数据…」中只读复制合并旧版目录的 `config/`（个人设置、地点标记、连线、已装插件）与 `cache/`（已扫描二维地图瓦片），不删除或修改旧目录原文件，导入后立即刷新当前界面配置与标记。
- **便携运行时 HTTPS 支持**：Windows 便携包自带运行时补齐 `jdk.crypto.ec` 模块并默认启用系统代理兼容，消除首帧 JavaFX 样式表加载告警。

## 自 0.7.5 以来的旧版与预扁平化存档兼容（0.7.6 – 0.7.8）

- **1.2.1 – 1.12.2 预扁平化存档读取（0.7.6）**：支持旧式 `Blocks` / `Add` / `Data` 区块解码、`level.dat` 中 Forge `FML.ItemData`（1.7.x）与 `FML.Registries`（1.8–1.12.2）数字方块 ID 还原、原版 `0..255` 方块与附加值归一，以及传统 `DIM<整数>` 维度发现。
- **1.13 – 1.21.x 客户端准入与群系着色回退（0.7.7）**：支持 1.13–1.16.5 客户端 JAR 准入、1.13–1.17.1 `Level.Biomes` 解码、`pack_format 4–14` 权重与 `multipart` 取反规则，以及未收录类指纹客户端的原版着色近似与维度高度/群系气候回退。
- **1.6.1 – 1.12.2 预扁平化三维纹理适配（0.7.8）**：支持 1.8–1.12.2 `textures/blocks` 双向查找、常见原版状态映射、内置流体回退与声明式 `forge_marker: 1` 模型；支持 1.6.1–1.7.10 常见原版方块静态几何贴图合成、`mods/<mcversion>/*.jar` 扫描及无多面歧义简单 Mod 单贴图近似（缺失客户端或超范围内容回退简化颜色底座并在解析诊断中说明原因）。

## 使用说明与已知边界

- Windows x64 便携包自带 Java 21，完整解压到普通可写文件夹后双击 `MC World Explorer.exe` 即可运行。升级自旧版便携包时，建议将新版 ZIP 解压到新文件夹并保留旧目录，首次打开新版即可导入旧版设置、标记与地图缓存。
- 大范围多群系过渡选区在当前 CPU 逐色阶预烘焙贴图机制下仍可能触发 `TextureAtlas` 贴图上限并回退简化颜色显示（计划在下一版本通过 GPU 顶点着色架构升级解决）；自定义渲染器与未知动态模型限制见[资源解析范围](../MODEL_PROTOCOL_CAPABILITIES.md)。
- 版本号、包指纹与验证记录见[当前状态](../progress/CURRENT.md)与[0.7.9 验证记录](../progress/V0.7.9.md)。
