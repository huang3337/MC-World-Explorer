# 0.7.5 版本说明

## 地图与地点

- 存档库支持搜索、排序和刷新。地图可按鼠标所在位置读取 X/Z 坐标，在已保存范围内定位地形。
- 命名地点可跨启动回访。拖动图标连线时实时显示 X、Z 轴距，适合测量路线或规划建筑间距。
- PNG 导出支持当前视口与指定坐标范围。二维首屏补图和已浏览区域的回访已优化。

## 三维与资源

- 基础档和增强档共用模型与着色协议。增强档支持自由框选最多 256 个区块。独立三维窗口可直接在中文输入法下使用 WASD。
- 改进原版模型分支、群系颜色、流体表面和部分 Forge／NeoForge 组合模型，修复特定角度下后方水面盖住前景冰面的问题。
- 自定义渲染器及未绑定的 Mod 颜色仍可能降级，详见[解析范围](../MODEL_PROTOCOL_CAPABILITIES.md)。
- 离线插件开发说明附有可直接发给 DSH、Claude Code 或 Codex 的构建提示词。用选区诊断和本地实例资源构建独立插件，安装并启用后可在同一选区复核。[提示词与示例](../PLUGIN_DEVELOPMENT.md#agent-prompt)

## 设置与便携使用

设置页整合外观、工具偏好、二维显卡、JVM 最大堆、二维扫描并发及三维缓存。二维显卡按型号选择，重启 MCWE 生效；最近一次三维窗口的实际设备另行显示。JVM 最大堆与缓存预算各自生效，整个进程的峰值还受原生库和驱动影响。[设置说明](../FAQ.md#render-settings)

Windows x64 便携包自带 Java，完整解压后运行 `MC World Explorer.exe`。版本号、包指纹与审核状态见[当前状态](../progress/CURRENT.md)，实测范围见[0.7.5 验证记录](../progress/V0.7.5.md)。
