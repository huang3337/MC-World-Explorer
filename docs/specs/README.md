# 当前技术规格索引

`docs/specs/` 只保存当前有效、可直接用于实现和验收的详细技术契约。规格可以包含数据结构、状态、容量、错误语义、流程和测试要求，但不记录方案争论、废弃路径、逐任务进度、单次执行日志或阶段完成状态。实现与验收进展只见[当前阶段状态](../progress/CURRENT.md)。

## 维护规则

- 规格必须表达当前唯一有效的契约；新结论生效后直接更新正文，不按日期堆叠修订章节。
- 已废弃方案应删除；需要保留的问题处理过程进入 `docs/issues/`，详细实施计划保留在 `docs/superpowers/`。
- 重大且长期的方向变化必须先获得开发者确认并记录到 `docs/decisions/`，规格随后落实该决策的技术细节。
- 规格索引中的“当前有效”只表示契约适用，不代表实现、测试或人工验收完成；这些阶段结论统一记入 `docs/progress/CURRENT.md`。
- 协议版本、缓存身份、资源上限、取消语义、错误分类和验收条件发生变化时，必须同步检查源码、测试、相关 Issue 与唯一实时阶段状态。
