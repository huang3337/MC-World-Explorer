# 版本冲突修正说明

- **生效日期**：2026-10-25
- **适用范围**：`tauri-rewrite` 的应用版本、实验阶段和文档引用

本文件用于解释此次编号修正及其与历史记录的对应关系，避免 Tauri 技术实验占用 Java 正式版本序列，也避免将旧提交、验收记录和发布附件误认为使用了新编号。这里不记录逐文件修改过程，不替代[当前阶段状态](progress/CURRENT.md)。

## 修正后的编号

Java 正式开发从稳定版 `0.6.0` 接续，后续正式版本由 Java 主线确定。Tauri 仅作为技术实验保留，当前源码独立编号为 `0.1.0`；如以后发布新的实验构建，标签使用 `tauri-v<版本号>`，与 Java 的 `v<版本号>` 区分。

应用版本与实验阶段分别编号，阶段完成不等于发布了一个软件版本：

| 修正前 | 修正后 | 含义 |
|---|---|---|
| Tauri 源码版本 `0.7.3` | Tauri 实验版 `0.1.0` | 本次仅修正编号与定位，不表示新增功能或补齐验收 |
| Tauri 阶段 V0.7.1 | T1 | 工程与边界 |
| Tauri 阶段 V0.7.2 | T2 | 最小端到端垂直切片 |
| Tauri 阶段 V0.7.3 | T3 | 二维加载问题簇收口与有限三维正确性补强 |
| Tauri 阶段 V0.7.4 | T4 | 原解析核心与二维功能对等计划，暂停 |
| Tauri 阶段 V0.7.5 | T5 | 原三维功能对等计划，暂停 |
| Tauri 阶段 V0.7.6 | T6 | 原迁移收口验证计划，暂停 |

T1–T3 的完成事实和既有验收边界保持不变；T4–T6 未实施，不作为 Java 后续开发的前置条件或产品承诺。

## 历史提交、文档与 Release

本次修正不重写已有提交或移动旧标签。修正前的提交仍按其当时编号解释；例如提交 `f756224724d76126befe62d673274bca22f88a01` 中的 Tauri V0.7.3 对应现在所称的 T3 阶段，不能据此解释未来 Java 的同名版本。

历史 Progress、Issue 原文及其目录保留旧编号，内容描述记录时点；当前文档使用 T1–T6，并继续链接原始证据。有效规格已改用 T2/T3 文件名，二进制 IPC 协议版本仍为 `1`，不随应用版本调整。

[现有 Tauri 技术预发行版](https://github.com/huang3337/MC-World-Explorer/releases/tag/v0.7.3-tauri.1) 的标题和说明按技术实验定位修正，旧标签 `v0.7.3-tauri.1`、目标提交、附件和校验值保留。该附件 EXE 内部仍为 `0.7.3`，属于历史 T3 构建；它不是新编号 `0.1.0` 的构建。本次未重新构建或发布 EXE。

后续阅读版本信息时，应同时确认 Java/Tauri 技术线、应用版本和源码提交；历史阶段编号不与 Java 正式版本比较大小。
