## 开发目标

- 地图块首次加载失败后自动重试一次。
- 持续失败时显示明确失败覆盖层，点击该地图块只重试该块。
- 玩家标记悬停显示玩家名称、维度和精确坐标。
- 点击玩家列表定位后短时高亮目标玩家。
- 缓存清理前显示文件数量与容量，清理后显示实际释放量。
- 将按钮更名为“清理存档缓存并重新加载”，沿用保留当前视图的重新加载行为。
- 将地图最大放大倍率扩展到 `2×` 和 `4×`，不增加新的地图块缓存级别。
- 建立 V0.3.1 完整自动化、真实存档、压力、升级和软件包验收门槛。

## 实际完成

- 新增独立 `MapTileLoadTracker`，管理有限自动重试、持续失败和单次手动重试。
- 控制器首次失败后只自动重试一次，第二次失败进入稳定可点击状态。
- 失败状态按当前世界与 `MapTileKey` 保存在运行时，不写入磁盘缓存。
- 视口为失败块绘制深色或旧画面底图、半透明红色斜线和红色边框。
- 失败块悬停显示“加载失败，点击重试”。
- 使用 4 个逻辑像素阈值区分点击与拖动，标记命中保持优先。
- 重试期间拒绝重复点击，失败块不阻塞其他地图块。
- 状态栏显示失败数量，存在失败或加载中地图块时保持 PNG 导出禁用。
- 新增运行时 `DisplayMapMarker`，没有修改地图瓦片缓存格式。
- 玩家 Tooltip 显示名称、维度显示名、维度 ID 和一位小数 X/Y/Z。
- 玩家列表定位时自动打开玩家标记，并为目标绘制约 3 秒绿色外圈高亮。
- 新玩家选择、切换维度或切换世界时清除旧高亮。
- `WorldMapCacheCleaner` 新增当前存档缓存文件数、字节数统计。
- 缓存清理返回实际删除文件数、释放字节数、失败条目数和首个错误。
- 部分文件删除失败时继续处理安全条目，并向界面报告实际结果。
- 按钮更名为“清理存档缓存并重新加载”。
- 清理前后台统计并显示确认；清理后保留维度、显示层、中心和缩放，重新请求当前视口。
- 清理操作不重新扫描玩家数据；传送门随地图块重新生成。
- 增加缓存维护状态，删除期间暂停新的地图块请求，避免缓存被并发写回。
- 新增 `MapDisplayZoom`，将七个显示级别与五个来源瓦片级别分离。
- 增加 `0.50` 和 `0.25 方块/像素` 两级视觉放大，分别将一个方块显示为 `2×2` 和 `4×4` 屏幕像素。
- 两个高倍率级别继续使用 `BLOCKS_1` 瓦片，未修改 `MapTileKey`、生成器、缓存路径或磁盘格式。
- 滚轮、`+`、`-`、指针锚定动画和状态栏均支持新级别；稳定在最大倍率后继续放大不会重复请求地图块。
- 重置视图和玩家列表定位继续使用默认 `2 方块/像素`。
