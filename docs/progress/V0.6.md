# V0.6 小范围三维预览进度

- **当前状态**：已完成并发布
- **完成确认日期**：2026-08-14
- **发布标签**：`v0.6.0`

## 目标

从二维地图选择受控区块范围，在后台生成简化三维场景，并通过唯一独立 LWJGL 窗口提供旋转、有限平移、缩放、重置、取消和失败恢复。

## 主要已完成能力

- 建立正式 `viewer` 模块、四档范围、基础/增强性能档、来源签名和有限 LRU 内存缓存。
- 建立 JavaFX 三维选择与二次确认、进度、取消、失败重试和缓存状态反馈。
- 建立唯一 GLFW/LWJGL 窗口、原子场景替换、旧请求拒绝和幂等关闭。
- 支持左键环绕、右键有限平移旋转中心、滚轮中心缩放和完整重置；单击与拖动使用明确阈值区分。
- 保持二维地图、便携目录和 Minecraft 存档严格只读边界。

## 验证概况

- 全量自动化、多个范围、主世界/下界/末地/Mod 维度真实体素管线、主程序启动和人工交互复验通过。
- 真实样本文件清单、大小、修改时间和内容哈希在验收前后保持一致。
- Rule 16 完成且没有活动问题，记录位于 `docs/issues/resolved/V0.6/`。
- Windows x64 最终包从确定提交干净构建并完成纯净启动、远端资产和标签核对。

## 当前限制

- 正式基础档限制为 1×1/3×3 和 256 MiB 场景缓存；更大范围取决于性能档和资源边界。
- 自动化未证明具体使用了哪块 GPU，其他显卡及远程桌面兼容性仍需后续验证。
- 左键单击只保留未来入口，本版本不加入方块拾取。

## 重大结论

正式三维窗口与交互边界见 Java DECISION-007 和 DECISION-008。
