# V0.6 小范围三维预览进度记录

## 当前状态

V0.6 已完成设计范围内的功能代码、全量自动化测试、真实存档体素管线验证、主程序启动验证和开发者人工交互复验。首轮人工体验发现双轴旋转方向与固定旋转中心问题后，已完成左键单击与拖动共存、双轴方向反转、右键有限平移旋转中心和滚轮中心缩放，并将左键旋转灵敏度由 `0.008` 调整为 `0.005`。Rule 16 已完成 31 个生产文件的逐文件审查，未发现活动问题。开发者于 2026-08-14 确认 V0.6 作为首次加入三维查看的正式发布版本；源码提交 `f169ebf7330172ea6c3c1b6e5fdda922e2b94278`、标签 `v0.6.0`、Windows x64 软件包和 GitHub Release 均已发布并完成远端核对。

## 开发目标

- 从二维地图选择受控方形区块范围并二次确认。
- 在后台读取完整高度体素并生成简化三维场景。
- 在独立 LWJGL 窗口中支持环绕旋转、俯仰、缩放和重置。
- 支持唯一窗口复用、任务取消、旧结果隔离和局部失败。
- 建立带来源失效检测的有限内存场景缓存。
- 保持二维地图稳定、Minecraft 存档严格只读和程序根目录便携边界。
