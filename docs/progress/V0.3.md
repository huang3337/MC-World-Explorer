# V0.3 地图浏览器开发进度记录

## 当前阶段

V0.3 已于 2026-07-28 经开发者明确授权正式开始实施，并于 2026-07-29 完成源码功能、自动化测试、真实存档只读验收、逐文件审查和开发者人工界面验收。

开发者已明确确认 V0.3 功能足够、版本开发完成，并允许按照 `DEVELOPMENT_RULES.md` Rule 18 创建统一提交并同步 GitHub。本版本不构建或发布软件包，等待 V0.3.1 完成最后完善后再评估。

## 开发目标

- 任意已有区块间自由拖动浏览。
- `1、2、4、8、16 方块/像素` 五级缩放。
- 当前维度和图层内的 X/Z 坐标定位。
- 单人及多人玩家、出生点和下界传送门标记。
- 玩家列表与跨维度玩家定位。
- 跨启动地图块缓存与按 Region 精确失效。
- 界面内清理当前世界缓存。
- 当前完整视口所见即所得 PNG 导出。

## 实际完成

- 建立固定 `256 × 256` 像素的五级地图块坐标、缩放和视口模型。
- 实现 128 项 LRU 内存缓存、便携磁盘缓存、Region 大小与修改时间精确失效、损坏缓存恢复和跨启动标记复用。
- 提取共享只读 Section 表示，让地表/高度带采样和传送门识别共用一次区块解析。
- 实现五级确定性图块生成、局部失败隔离、当前图块传送门提取和跨图块合并。
- 实现最多两个后台任务、中心优先级、一圈预取、约 200ms 防抖、取消和旧请求隔离。
- 使用独立 `MapViewport` 与 `MapViewerController` 接入自由拖动、指针锚定滚轮缩放、缩放按钮和重置视图。
- 完成已确认的顶部双层工具栏、整数 X/Z 定位和三类标记显示开关。
- 初次打开存档和首次切换维度固定显示地表总览；三类标记开关加入与地图一致的绿色、黄色和紫色图例。
- 只读解析 `playerdata/*.dat` 中全部有效玩家的最后位置和维度，并从受限范围内的 `usernamecache.json`、`usercache.json` 恢复名称；缺失名称时回退短 UUID。
- 工具栏加入带人数的玩家列表；点击玩家会自动切换到对应可用维度，以地表总览、`2 方块/像素` 和玩家坐标为中心显示。
- 多人数据有效时使用全部 `playerdata` 玩家标记，未发现有效多人数据时继续回退 `level.dat` 单玩家位置。
- 标记提示改为只在鼠标实际命中标记时显示，拖动、缩放和状态切换时主动关闭，修复空 Tooltip 黑色小框。
- 滚轮期间使用连续视觉比例缩放，停止后吸附到最近离散档位；新级别完成前保留并拉伸旧图块，避免画面瞬间清空。
- 首轮只请求实际可见图块，图块内部按视口中心优先解析，并以透明局部快照渐进显示；可见区完整后再启动一圈低优先级预取。
- 完成界面二次确认的当前世界缓存清理，并同时覆盖 V0.2.1 静态预览缓存。
- 完成仅在全部请求图块就绪时可用的当前视口 PNG 导出，继续遵守默认 `exports/`、不覆盖和禁止写入存档规则。

## 遇到问题

- 图块生成结束后取消仍可能写缓存：已在写入前增加二次取消检查。
- 传送门提取异常可能连带丢失地形：已增加独立降级边界和日志。
- 默认线程池工作线程可能妨碍窗口退出：已改为有序命名的守护线程。
- 连续缩放动画会累积旧关键帧：已在每次动画前清空旧关键帧和完成回调。
- 跨请求保留图块仍使用旧回调：已让保留任务重新绑定最新请求、优先级和完成回调。
- 空标记 Tooltip 在缩放时可能显示黑色小框：已改为只在实际命中标记时手动显示。
- 玩家后台读取完成时可能访问不存在的当前维度：已增加维度存在检查。
- 手动切换维度可能误用旧玩家定位请求：已在目标不一致时清除暂存定位。
- 八项问题均已记录在 `docs/issues/resolved/V0.3/`，审查汇总为 8 项（🟠 5 / 🟡 3），当前活动问题为 0。
