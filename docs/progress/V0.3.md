# V0.3 地图浏览器进度

- **当前状态**：已完成，未单独发布软件包
- **开发开始日期**：2026-07-28
- **完成日期**：2026-07-29

## 目标

把静态预览扩展为可拖动、分级缩放、坐标定位、玩家/出生点/传送门标记、缓存复用和所见即所得导出的动态二维地图。

## 主要已完成能力

- 建立固定 256×256 像素、1/2/4/8/16 方块每像素的地图瓦片模型。
- 建立有限内存缓存、便携磁盘缓存和按 Region 状态精确失效。
- 使用两个有界后台 worker、中心优先级、可见区优先、一圈延迟预取、取消和旧请求隔离。
- 支持自由拖动、指针锚定缩放、整数坐标定位和当前视口 PNG 导出。
- 只读解析多人玩家位置，显示玩家、出生点和下界传送门标记并支持跨维度玩家定位。
- 图块内部提供渐进局部画面；新倍率完成前保留旧画面，避免缩放时瞬间清空。
- 支持确认后清理当前世界缓存并重新加载当前视图。

## 验证概况

- 全量自动化、真实主世界/下界/末地/Mod 图块、多人数据、JavaFX 启动和人工界面验收通过。
- 有内容图块验证了中心优先的早期局部结果；所有真实样本文件在测试前后保持不变。
- 八项审查问题全部解决并归档至 `docs/issues/resolved/V0.3/`，活动问题为 0。

## 当前限制

- 本版本不构建 Windows 软件包，不创建标签或 Release。
- 失败重试、高倍率视觉放大和缓存维护体验留给 V0.3.1。
