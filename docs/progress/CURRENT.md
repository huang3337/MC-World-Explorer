- 二维入口不再等待固定 1024×1024 表面；正式地图采用独立双 worker 有界调度，按可见目标中心优先生成，并持续提交局部瓦片结果。

- 世界切换、视口替换、组件卸载和应用关闭的地图任务收束及迟到结果隔离已补强；代表性真实存档场景下的关闭体验得到开发者确认。
