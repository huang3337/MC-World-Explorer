# 后续版本范围

0.7.4 已按本期范围完成交付。以下能力不在本期源码、测试源集、任务或应用包内：

- Mod 专用适配与插件，包括 Framework、暮色森林、Quark、Supplementaries。
- 花箱、动态注册恢复、生成资源、容器物品/实体、软液体和未知颜色回调。
- SDK 分发/生成器、模板、全实例缺项清零及未来游戏版本适配。

通用安装、启停、更新、卸载和隔离 worker 属于本体，不在延期范围。专用探索材料留在仓库外，后续立项时重新核对消费者、准入依据与接口后决定复用或废弃，不自动恢复旧路线。

此前未单独测量的性能指标和旧冷加载差距，作为 [0.7.4 已知限制](V0.7.4.md)保留事实；版本发布不代表这些指标已经重新实测或达标。后续优化另行确定范围。
