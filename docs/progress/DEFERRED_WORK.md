# 后续版本范围

[DECISION-024](../decisions/DECISION-024.md) 将以下专用探索列为 0.7.4 交付范围之外的工作：

- Mod 专用适配与插件，包括 Framework、暮色森林、Quark、Supplementaries。
- 花箱、动态注册恢复、生成资源、容器物品/实体、软液体和未知颜色回调。
- SDK 分发/生成器、模板、全实例缺项清零及未来游戏版本适配。

通用安装、启停、更新、卸载和隔离 worker 属于本体，不在延期范围。专用探索材料留在仓库外，后续立项时重新核对消费者、准入依据与接口后决定复用或废弃，不自动恢复旧路线。

此前未单独测量的性能指标和旧冷加载差距，作为 [0.7.4 已知限制](V0.7.4.md)保留事实；版本发布不代表这些指标已经重新实测或达标。后续优化另行确定范围。

## 后续单独立项方向

- **无 UI 开发者核心库后续演进**：`0.8.1` 已按 [DECISION-025](../decisions/DECISION-025.md) 完成 `:mc-world-explorer-sdk` 物理拆分与 Wavefront OBJ / 二维 PNG 导出门面（回应 GitHub Issue #1），不包含 `0.7.4` 已退出的专用 Mod 协议或插件生成器；更多三维交换格式（如 glTF）留待后续按实际反馈评估。
- **历史版本默认状态表**：1.13–1.19.4 热门长期版本的 `block-defaults.tsv` 默认属性表补充留待单独立项评估。
- **存档与功能扩展**：完整存档管理、实体统计、全图导出及主动编辑模式留待单独立项。Java 主线读取已保存区块；生成未探索区块需要运行世界生成器，仍处于可行性讨论阶段。现行工作范围见[当前状态](CURRENT.md)。
