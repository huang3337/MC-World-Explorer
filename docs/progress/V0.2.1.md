# V0.2.1 多维度预览与洞穴分层进度

- **当前状态**：已完成并发布
- **开发开始日期**：2026-07-18
- **完成与发布日期**：2026-07-24
- **发布标签**：`v0.2.1`

## 目标

让主世界、下界、末地和可验证的 Mod 维度共用预览、采样、渲染与缓存流程，并提供地表总览和 32 格高度带。

## 主要已完成能力

- 发现原版与 Mod 维度 Region 入口，并从目标维度的真实区块确定可用高度范围。
- 建立统一维度、图层和预览请求模型；玩家位置只在维度一致且坐标可靠时作为默认中心。
- 保留地表总览并新增 32 格高度带采样，正确处理跨 Section 空气、缺失数据和局部损坏。
- 按世界、维度、中心、图层、高度范围和渲染版本隔离缓存。
- 在 JavaFX 中提供维度选择、地表按钮和平滑高度滑块，并为每个维度独立保存本次运行状态。
- 切换请求取消旧任务，旧结果不得覆盖当前界面；导出继续遵守 V0.2 路径保护。

## 验证概况

- 自动化测试、真实多维度目录测试、实际启动和人工界面验收通过。
- 主世界、下界、末地和 Mod 维度样本均完成只读预览验证，相关 `level.dat` 与 Region 文件前后未变化。
- 最终审查问题已处理；详细证据保存在 `docs/issues/resolved/V0.2.1/`。
- Windows x64 便携包完成结构、校验和实际启动验收，并随 GitHub Release 发布。

## 当前限制

- 不包含地图拖动、连续缩放、坐标跳转、标记、纹理资源包或三维浏览。
- 不预生成全部维度与高度带，也不推测玩家在其他维度的历史位置。
