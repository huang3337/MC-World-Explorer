# MC World Explorer V0.7.2 进度

- **版本定位**：V0.7 框架迁移的首个正式二维、三维端到端版本
- **当前状态**：已完成；核心垂直链路、目录发现、有限二维/三维范围、自动化和必要桌面验收已经收口
- **完成日期**：2026-09-13
- **目标分支**：`tauri-rewrite`
- **稳定基线**：Java V0.6.0，保留在 `main`

## 目标

使用正式 Rust、Tauri、Vue 和 Three.js 模块打通：

世界发现与选择 → 只读 WorldSession → Region/Chunk 解析 → 二维地图 → 有限选区 → 简化三维 → 取消、错误隔离和关闭释放。

迁移后的用户体验与错误语义默认以 Java 稳定版为基线，Minecraft 存档始终严格只读。

## 主要已完成能力

- 已建立受保护的 Windows 只读世界来源、便携 WebView 数据目录和单窗口关闭协调。
- 已实现 `level.dat`、Anvil Region、NBT、现代与较早 Palette 布局的受限读取，并保持缺失、损坏、不支持和取消的分类。
- 已实现世界目录扫描、候选列表、受控打开和唯一只读 WorldSession；前端不获得世界文件路径访问能力。
- 已实现 Rust 表面采样、简化三维网格生成、JSON/二进制混合 IPC 及 TypeScript 严格解码边界。
- 已实现 Canvas 2D 地图、平移缩放、坐标定位、有限三维选区，以及 Three.js 内嵌三维显示和资源释放。
- 已恢复 1×1、3×3、5×5、8×8 三维范围预设和 Java 基线中的有限相机交互。
- 已完成自动化回归、生产前端构建和单可执行文件形态的桌面验证；真实存档只读与退出后资源释放已有证据。

## 已知限制与后续工作

- 二维入口仍受固定 1024×1024 表面阻塞，随后瓦片链路重复读取和采样。
- 可见瓦片仍串行等待，尚未提供 Java 对等的双 worker、中心优先、外围预取和单瓦片渐进结果。
- 当前视口完整度、整瓦片请求失败以及未加载区域的表达尚不可靠。
- Rust 尚未提供跨瓦片请求的有界会话内区块和最终瓦片复用。
- 当前单 worker 执行边界不能承载目标多瓦片调度；后续按重大决策重新规划地图专用调度、渐进结果和缓存。
- 5 秒关闭等待预算尚未经过真实二维负载验证。
- 多维度、玩家和标记等其余 Java 二维功能仍按后续里程碑恢复。

## 验证概况

- Rust 格式检查、Clippy、workspace 测试、TypeScript 类型检查和前端 Vitest 已用于当前实现回归。
- Rust 与 TypeScript 二进制协议使用固定黄金字节和畸形载荷验证。
- 已批准真实存档曾用于只读准确度、扩大范围、三维生成和资源释放验证；相关问题与解决证据保存在 Issues。
- 当前测试仍缺少真实多瓦片调度、冷/热缓存、首批可见时间、当前视口完整时间和真实负载关闭预算；这些验证随对应活动 Issue 转入 V0.7.3。

## 当前重大决策

当前有效决策为 [DECISION-011 至 DECISION-023](../decisions/README.md)。其中 DECISION-022 要求默认继承 Java 稳定行为，DECISION-023 已确认二维地图采用独立有界渐进调度架构。

## 活动问题

- `ISSUE-USEWORLD-001`：固定表面阻塞首屏并与瓦片链路重复计算。
- `ISSUE-MAPVIEWPORT-001`：可见瓦片串行加载且没有渐进结果。
- `ISSUE-MAPVIEWPORT-002`：当前完整状态不能证明存档已有区块已经完整显示。
- `ISSUE-RUSTMAP-001`：瓦片请求之间没有解析与采样结果复用。
- `ISSUE-EXECUTOR-004`：原全局单任务执行器不能承载多瓦片调度。
- `ISSUE-TAURILIB-004`：5 秒关闭等待预算尚待真实负载验证。

这些问题未在 V0.7.2 中伪装为已解决，继续保留在活动目录，由 V0.7.3 重新规划和实施。活动状态、原始审查快照和后续解决证据以 [Issue 索引](../issues/ISSUE_INDEX.md) 为准。

## 完成结论

V0.7.2 以“最小端到端垂直切片”完成，不以本里程碑宣称完整 Java 二维体验、可比性能结论或最终关闭预算。当前实现、自动化、真实存档只读和基础资源释放证据足以作为下一阶段的正式基线；活动问题不关闭、不归档，并由 V0.7.3 重新制定合格规格和实施计划。

里程碑提交、推送、构建发布版 EXE、标签和 Release 均需分别获得开发者明确授权。
