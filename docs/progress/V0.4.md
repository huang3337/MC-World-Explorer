# V0.4 三维技术可行性验证进度

- **当前状态**：已完成的内部技术验证
- **完成确认日期**：2026-08-01

## 目标

隔离验证真实区块完整 Section/方块状态解析、简化网格、JavaFX 3D 与 LWJGL/OpenGL 两种后端、Windows x64 性能和资源释放，为后续三维后端作出重大决策。

## 主要已完成能力

- 建立与正式二维入口隔离的三维数据、网格、相机、报告和双后端验证代码。
- 支持现代与有限旧布局、填充与紧凑位存储、负 Section Y、目标区块及水平邻区块。
- 生成普通方块外表面和原版流体空气接触外壳，两后端消费同一不可变网格快照。
- 建立一致的窗口、相机、交互、截图、报告和自动关闭验证入口。

## 验证概况

- 自动化、原始 NBT 独立逐位交叉验证、真实存档只读、双后端截图、性能采样和非发布 app-image 验收通过。
- 真实样本覆盖多个 DataVersion、单调色板及多种位宽；不支持和损坏数据被明确隔离，未伪装为成功。
- 两后端后半程内存均收敛；本机独显样本中 LWJGL/OpenGL 的上传、P95 帧时和工作集更优。
- Rule 16 发现的问题全部解决并归档至 `docs/issues/resolved/V0.4/`。

## 当前限制

- 仅验证小范围区块和简化几何，不包含正式入口、纹理、复杂模型、透明排序或动态加载。
- 预扁平化 `Blocks/Data`、外部 `.mcc` 及非 NVIDIA 图形环境未获得真实验证。

## 重大结论

开发者确认后续正式三维后端采用 LWJGL/OpenGL；当前有效记录见 Java DECISION-005。

## 下一阶段

V0.5 建立共享三维数据与渲染基础；V0.4 本身不发布用户软件包。
