# V0.1.1 代码质量与存档兼容性加固进度

- **当前状态**：已完成并发布
- **完成日期**：2026-07-12
- **发布日期**：2026-07-13
- **发布标签**：`v0.1.1`

## 目标

在 V0.1 基础上完成审查问题整改、可重复构建与启动环境，并修复大型整合包 `level.dat` 无法识别的问题。

## 主要已完成能力

- 加固日志、全局异常处理、类型安全、缺失字段表达和 JavaFX 后台扫描。
- 补齐 Gradle Wrapper 与 Windows 启动脚本，使项目不依赖系统全局 Gradle。
- 使用 16 MiB 有界 NBT 读取支持大型整合包存档，并保留异常输入的内存上限。
- 统一用户目录扫描入口，支持游戏根目录、`saves`、`versions`、实例目录和单个世界。
- 补齐详情字段并完成内置 Java 21 运行时的 Windows x64 便携包。

## 验证概况

- 自动化测试、真实整合包目录解析、JavaFX 启动和便携包实际启动均通过。
- 真实样本 `level.dat` 在验收前后大小和修改时间保持一致，确认测试路径只读。
- 本版本发现的 42 个问题全部解决并归档至 `docs/issues/resolved/V0.1.1/`。

## 当前限制

- 不解析或写入 Region、玩家数据及其他后续版本内容。
- 软件包未签名，Windows 可能显示 SmartScreen 提示。
