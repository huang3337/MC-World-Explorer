# V0.7.6 开发与验证记录

各节按验证日期与构建区分。现行源码、发布状态与待办见[当前状态](CURRENT.md)，通用解析准入与边界见 [DECISION-024](../decisions/DECISION-024.md)。

## 目标与实际完成

0.7.6 为 1.2.1–1.12.2 预扁平化（Pre-Flattening）Anvil 存档补齐只读解析链路，覆盖原版及 Forge 动态方块 ID 存档的二维完整地图与三维简化颜色底座：

- **Forge `level.dat` 数字方块 ID 映射**：`SavedLegacyIdMap` 只读解析 1.7.x 根级 `FML.ItemData`（过滤 `0x02` 物品项、提取 `0x01` 方块项并保留原始大小写命名空间）与 1.8–1.12.2 `FML.Registries`（`fml:blocks` / `minecraft:blocks`），设 32,768 条目与 `0..4095` ID 范围校验，冲突或损坏标签明确拒绝。无 `Data.Version` 且 `Data.version == 19133` 的旧存档统一标为 `Anvil (<1.9)`。
- **预扁平化区块 Section 解码**：`ChunkNbtDecoder` 新增 `LEVEL_LEGACY` 分支，拒绝同一区块混用 `Palette` 与 `Blocks` 的异常结构；`LegacyAnvilSectionDecoder` 严格校验 `Blocks[4096]`、`Data[2048]` 与可选 `Add[2048]` 字节数组长度，拒绝非零 `Add2` 超 4096 扩展 ID，按 YZX 半字节序合成 12 位方块 ID 与 4 位附加值并归并为紧凑调色板 `ChunkSection`。
- **原版 `0..255` 数字方块与附加值归一**：`VanillaLegacyBlocks` 优先查询存档 `SavedLegacyIdMap`，回退原版 `0..255` 静态表，对染色羊毛、染色陶瓦、染色玻璃、地毯、混凝土、木种、石材变种、双层植物、流体及下界传送门归一为标准标识并在三维状态保留 `data` 属性；未知数字 ID 保留确定性身份 `legacy:block_<id>`，不静默丢弃为空气。
- **传统维度发现与简化分类**：`WorldDimension` 与 `WorldDimensionDiscovery` 按规范有符号 32 位十进制整数识别存档根下 `DIM<整数>/region`（`0`、`-1`、`1` 归一到原版三维度，其余映射为 `legacy:dim_<n>` 并与玩家数值维度对齐，忽略前导零与溢出目录）；`PortalMarkerExtractor`、`BlockClassifier` 与 `BlockColorPalette` 补齐预扁平化传送门、流动流体、植被与染色方块分类。
- **缓存来源联动与资源边界降级**：二维磁盘瓦片缓存 `MapTileCache`、持久摘要 `SurfaceSummaryStore`、内存摘要及三维 `RegionSourceSignature` 均纳入 `level.dat` 文件指纹，二维与三维渲染版本标识递增至 `v076-p1` 与 `v076-model-protocol-1`；`ClientResourceLocator` 对预扁平化版本直接提示三维使用简化颜色底座，`BuiltinBlockModels` 安全跳过含大写字符的旧版 Mod 注册名并保留准星身份与诊断。

### 已知限制与未纳入范围

- 1.7.10 及更早版本不存在 JSON blockstate/model 体系，1.8–1.12.2 使用旧版 `textures/blocks` 路径及大量运行期状态；本期不为预扁平化存档烘焙三维纹理模型，三维预览统一使用简化颜色底座。
- 1.13–1.21.x 中间版本的整数型 `pack_version`、`Level.Biomes` 数值群系数组及未核实客户端的植被着色回退未纳入本期，见[后续版本范围](DEFERRED_WORK.md)。
- McRegion `.mcr` 及更早格式、非零 `Add2` 超 4096 扩展方块 ID 继续按不支持格式明确报告。
- 0.7.6 已合入主线源码，尚未创建 `v0.7.6` 标签或 Windows 便携发行包。
