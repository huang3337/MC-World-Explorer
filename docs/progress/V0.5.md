# V0.5 三维数据与渲染基础进度记录

## 当前状态

V0.5 已于 2026-08-04 获开发者确认并开始实施。设计范围内的代码、自动化、真实存档验证和 Rule 16 审查已经完成；开发者于 2026-08-14 完成人工审核并明确确认 V0.5 整体完成。V0.5 不接入正式主界面，也不构建或发布用户软件包。

## 开发目标

- 建立共享的完整方块状态、Section 和 Chunk 解析核心。
- 在保持 V0.3.1 二维行为不变的前提下，让二维采样使用共享解析。
- 支持最大 `8x8` 目标区块及外围一圈的只读加载与错误隔离。
- 生成不透明、镂空、半透明、流体和降级层的简化网格。
- 建立后端无关网格快照及正式 LWJGL/OpenGL 上传、绘制和释放组件。
- 提供独立 `experimental.v05` 验证入口、JSON 报告和截图。
- 使用真实存档证明解析正确、局部失败可隔离且 Minecraft 文件没有变化。

## 已确认边界

- Palette 系列区块继续支持；旧式 `Blocks/Data`、外部 `.mcc` 和未知布局明确局部失败。
- 未知及 Mod 方块保留完整 ID 和属性，并以不透明降级方块处理，不使用名称关键词猜测。
- V0.5 不实现纹理、复杂模型、动态区块流送、持久三维缓存或正式用户入口。
- V0.4 实验代码保留为历史验证证据，不继续承载正式功能。
- 重大架构决策见 `docs/decisions/DECISION-008.md`。
