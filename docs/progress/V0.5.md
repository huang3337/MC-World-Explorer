# V0.5 三维数据与渲染基础进度

- **当前状态**：已完成
- **开发开始日期**：2026-08-04
- **完成确认日期**：2026-08-14

## 目标

建立二维与三维可共享的完整方块状态解析、有限范围加载、分层简化网格和正式 LWJGL/OpenGL 资源组件，同时保持二维行为和存档只读边界不变。

## 主要已完成能力

- 建立共享完整方块状态、Section 和 Chunk 解析核心，二维采样通过适配层复用同一解码器。
- 支持最大 8×8 目标区块及外围一圈、逐区块状态、局部失败、取消和部分成功。
- 生成不透明、镂空、半透明、流体和未知方块降级层的后端无关网格快照。
- 建立 LWJGL/OpenGL 上传、原子场景替换、绘制、着色器和显式资源释放组件。
- 保留独立实验入口，用于截图、报告、性能和只读验证，不接入正式主界面。

## 验证概况

- 全量自动化及独立逐位解析交叉验证通过。
- 主世界、下界、末地和 Mod 维度均完成真实加载、网格、截图和结构化报告验证。
- 真实存档文件清单、大小、修改时间和内容哈希前后相同；输出路径回绕存档的尝试在写入前被拒绝。
- 最大范围验证完成，OpenGL 资源释放后未发现遗留进程或存档文件锁。
- Rule 16 问题全部解决并归档至 `docs/issues/resolved/V0.5/`。

## 当前限制

- 不支持旧式 `Blocks/Data`、外部 `.mcc`、纹理、复杂模型、动态区块流送或持久三维缓存。
- 未知及 Mod 方块保留完整状态并以不透明降级方块显示，不按名称猜测模型。
- 本版本不构建或发布用户软件包。

## 重大结论

共享三维核心与渲染边界的当前有效记录见 Java DECISION-006。
