# V0.7.4：通用解析与三维交互

发布日期：2026-11-05。0.7.4 完成通用解析、三维交互、关于页面、新图标与选区修复，正式发布零预装插件的Windows便携包。正式版本已重新测试和构建，结果见[CURRENT](CURRENT.md)。范围依据 [DECISION-024](../decisions/DECISION-024.md)。

## 目标与实际交付

- JavaFX 主界面与独立 LWJGL 三维窗口；只读世界，不启动 Minecraft。
- 标准资源模型、普通 OBJ 和有依据的标准颜色处理；来源校验、资源顺序和预算保留。
- 已加载场景内 WASD/鼠标/升降、Alt 捕获释放、Esc 释放/关闭及失焦清键。
- 准星目标信息与加粗线框，保留原始方块身份、Mod、坐标及解析状态。
- 主界面全局“关于”：工具说明、真实构建版本、作者、项目地址、许可证及复制信息；不选择世界也能使用。
- 资源、解析诊断、插件三页；诊断按本次选区分组，说明失败、降级、来源和截断，支持导出。
- 通用插件安装、更新、启停和卸载；项目与应用包均零安装、零预装。离线开发说明提供当前接口的完整示例。

本期不交付专用 Mod 适配、SDK 生成器、容器/实体/注册探索或动态区块流送，详见 [后续范围](DEFERRED_WORK.md)。通用格式成功不代表整个 Mod 或全部资源支持。

## 已知限制

颜色协议的当前证据限定于1.20.1/1.21.1对应客户端；未知模型/回调明确降级。诊断只涵盖生成选区，存在有说明的预算上限。插件worker是生命周期隔离，不是权限沙箱。

二维和三维读取磁盘存档，不与正在运行的游戏实时同步。二维普通刷新可能沿用内存瓦片；三维重开检查Region签名，但不构成与游戏写盘协调的一致快照。在线更新的刷新步骤与边界见[常见问题](../FAQ.md)，本轮仅核对源码，未启动游戏实测。
