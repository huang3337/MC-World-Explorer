各节按验证日期与构建区分。现行源码、发布状态与待办见[当前状态](CURRENT.md)，通用解析准入与边界见 [DECISION-024](../decisions/DECISION-024.md)。

## 目标与实际完成

0.7.7 补齐 1.13–1.21.x 全区间客户端资源准入、旧版区块数字群系解码、模型变体格式范围及未收录静态类指纹与 1.19.3 前客户端的原版世界着色回退链路：

- **1.13–1.16.5 客户端 JAR 元数据准入**：`ClientResourceArchive.parseMetadata` 支持 1.14–1.16.5 `version.json` 的单正整数型 `pack_version`（同时保留 1.17+ 对象型 `resource` / `resource_major` / `resource_minor` 严格校验）。对不含 `version.json` 的 1.13–1.13.2 客户端 JAR，在校验基础石头资源三件套与 `pack.mcmeta`（严格解析 `pack.pack_format == 4`）后允许只读打开；其余缺失 `version.json` 的归档继续拒绝。
- **旧版 `Level.Biomes` 数字群系解码与原版群系气候表**：新增 `VanillaLegacyBiomes`，收录 1.2–1.17.1 标准原版数字群系 ID 映射及 1.2–1.19.2 原版群系基础气候与水色表（含 1.13–1.19.2 名称别名）；`BiomeSection` 新增受控 `fromCells` 与 `invalid` 工厂方法。`ChunkNbtDecoder` 在场景解码下读取非 `MODERN_ROOT` 区块的 `Level.Biomes`：`int[1024]`（1.15–1.17.1）按 4×4×64 切分为 `Section 0..15`，`int[256]`（1.13–1.14.4）与无符号 `byte[256]`（1.2.1–1.12.2）按 4×4 水平格扩展填充；未知数字群系 ID 或畸形数组标为 `BiomeSection.INVALID` 保留原因，不中断或丢弃方块几何。
- **`pack_format 4–14` 模型变体与 `multipart` 兼容**：`WeightedVariants.protocol` 将旧式权重抽取范围扩展至 `pack_format 4..36`；`BlockModelResolver.multipartProperty` 将多值否定下界从 `15` 放宽至 `4`，1.13–1.19.4 客户端统一采用整组取反语义。
- **未收录类指纹与 1.19.3 前客户端原版世界着色回退**：
  - `vanilla-tint-layers.json` 的 `worldGrass` 分组补入 1.13–1.20.2 矮草标识 `minecraft:grass`（与 1.20.3+ `minecraft:short_grass` 并列），并在 `compatibleBuilds` 中显式声明 `26.1` 版本标识。
  - `VanillaTintLayers` 与 `ClientBlockColors` 严格保留已登记类指纹版本（`1.20.1`、`1.21.1`、`1.21.5`、`26.1`、`26.3`）的静态校验与类篡改拒绝边界；仅对未建立类指纹档案且 `pack_format >= 4` 的其他版本提供通用原版颜色层分组回退（`pack_format < 35` 不启用 `dryFoliage`，`pack_format >= 84` 切换为 `particleWater` 与非重复层尾），并在诊断来源说明中明确标注“通用近似，未经该版本客户端字节码静态注册核对”。
  - `SavedBiomeColors` 在基础客户端已确认未内置 `data/minecraft/dimension_type/` 时为原版三维度提供标准高度回退（`pack_format 4..7` 统一为 `0..255`，`pack_format >= 8` 主世界为 `-64..319`、下界与末地为 `0..255`）；在基础客户端已确认未内置 `data/minecraft/worldgen/biome/` 时为 `minecraft:` 群系查询 `VanillaLegacyBiomes` 气候与水色表并继续读取客户端真实 `colormap/grass.png` 与 `colormap/foliage.png`，同时在诊断说明中如实记录近似来源。已内置数据注册表的 1.19.3+ 客户端保持原有严格缺失报错。
  - `LayeredResourceSource` 补齐对基础客户端版本、内置数据注册表、受预算约束的 `clientClass`、世界群系输入及有界来源追踪的委托。
- **构建与缓存版本递增**：`build.gradle` 递增至 `0.7.7` 与 `build/core-0.7.7`，`tools/package-windows.ps1` 与 `VoxelPreviewCoordinator.RENDER_VERSION`（`v077-model-protocol-1`）同步更新。

### 已知限制与未纳入范围

- 0.7.7 已合入主线源码并通过离线自动回归与核心隔离校验，尚未执行真实旧版客户端 JAR 现场实测、原生窗口人工验收，也未创建 `v0.7.7` 标签或 Windows 便携发行包。
- `block-defaults.tsv` 默认方块属性表当前未补充 1.13–1.19.4 历史数据版本快照；区块数据版本未收录时，仍依赖无条件模型与区块中显式保存的属性。
- 未收录字节码指纹版本的原版世界着色以及 1.13–1.19.2 缺失内置数据注册表时的维度高度与群系气候属于基于标准原版表的近似回退，不构成对应客户端字节码的静态注册证明。
- 1.6–1.12.2 预扁平化客户端资源的旧式纹理路径与三维模型烘焙仍未纳入本期。
