# V0.2 世界缩略图进度

- **当前状态**：源码目标已完成，成果并入 V0.2.1 发布
- **完成日期**：2026-07-18

## 目标

在不启动 Minecraft、不依赖外部程序且不修改存档的前提下，生成、显示并导出主世界静态俯视缩略图。

## 主要已完成能力

- 建立严格便携的缓存、日志、配置和导出目录边界。
- 从 `level.dat` 解析预览中心，读取 Anvil Region 头、区块压缩数据、现代 Section 与 Palette。
- 采样主世界地表并生成 PNG，支持内置 JavaFX 预览、后台任务、取消和错误提示。
- 建立内存与磁盘缓存，并按中心、渲染版本、`level.dat` 与相关 Region 文件状态失效。
- 支持当前预览 PNG 导出，拒绝覆盖现有文件及写入 Minecraft 世界目录。

## 验证概况

- 自动化测试覆盖路径、Region、解压、Palette、采样、缓存、导出和异步状态。
- 真实存档缩略图生成与界面预览通过；相关 Minecraft 文件在验证前后大小、时间和内容哈希一致。
- 整体代码审查完成，问题处理证据保存在对应 resolved Issue 中。

## 当前限制

- 仅提供固定范围主世界地表缩略图，不含多维度、洞穴分层、拖动、连续缩放或三维。
- V0.2 未单独发布，其成果随 V0.2.1 统一交付。

## 下一阶段

V0.2.1 引入多维度与高度带预览。
