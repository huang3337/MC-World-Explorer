# V0.1 存档管理器进度

- **当前状态**：已完成
- **完成日期**：2026-06-18

## 目标

完成能够扫描 Minecraft Java 版存档目录并显示基础世界信息的最小可用产品。

## 主要已完成能力

- 建立 Java 21、JavaFX 和 Gradle 项目基础。
- 只读解析 `level.dat`，显示世界名称、版本、模式、游玩时间、种子和玩家坐标等基础信息。
- 扫描默认目录及用户选择目录，隔离损坏存档并返回可用世界列表。
- 建立存档列表、图标和详情面板，并支持保存自定义目录选择。

## 验证概况

V0.1 完成时以静态审查和人工运行验收为主；V0.1.1 后续补齐 Gradle Wrapper，并用自动化测试重新验证相关基础能力。

## 当前限制

不包含 Region 地图、缩略图、多维度或三维功能。

## 下一阶段

V0.1.1 负责代码质量、构建环境和整合包兼容性加固。
