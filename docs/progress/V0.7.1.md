# MC World Explorer V0.7.1 进度

- **当前状态**：已完成
- **目标分支**：`tauri-rewrite`
- **完成确认日期**：2026-09-06

## 目标

建立 Tauri 迁移的最小可运行工程和不可越过的安全边界，在不迁移地图或三维业务的前提下验证 Rust、Tauri、Vue、便携路径、错误传播和任务生命周期基础。

## 主要已完成能力

- 建立 Tauri 2、Rust workspace、Vue 3 和 TypeScript 工程，并创建不依赖 Tauri 的 `mcwe-core`。
- 建立严格只读的 `WorldSource`/`WorldFile` 边界，拒绝路径逃逸和重解析点，不向前端暴露任意路径或文件句柄。
- 建立程序目录派生的便携路径、类型化应用错误和最小任务登记机制。
- 建立单一类型化前端 IPC 服务和最小状态页，验证前后端通信、空数据和错误状态。
- 将 WebView 数据目录限制在程序便携目录，并建立窗口关闭、任务取消和资源释放顺序。
- 完成 Windows x64 原生 no-bundle 构建、单 EXE 生命周期、目录解锁和真实存档只读验收。

## 验证概况

- Rust 格式、Clippy、workspace 测试、编译失败边界测试、TypeScript 类型检查、前端测试和生产构建均通过。
- 单 EXE 验证确认 WebView 数据写入便携目录，正常关闭后相关进程结束、目录可移动且 AppData 未发生变化。
- 真实存档验收只读取受控样本；验收前后文件清单、大小、修改时间和必要哈希一致。
- Rule 16 最终审查及复审完成，V0.7.1 活动问题为 0；详细问题证据保存在 `docs/issues/resolved/V0.7.1/`。

## 当前限制

- 本里程碑没有迁移 NBT、Region、二维地图或三维功能。
- 正式目标仅为 Windows x64；其他平台不在本里程碑保证范围内。
- 路径安全策略拒绝所有重解析点，即使其最终目标仍位于允许目录中。

## 重大决策

当前有效结论见 Tauri DECISION-011 至 DECISION-014：迁移技术栈、Windows 文件句柄保护、WebView 便携目录和协同关闭。

V0.7.1 已完成并同步至 `tauri-rewrite`。后续能力由 V0.7.2 独立记录；V0.7.1 的完成不授权合并 `main`、创建标签或发布。
