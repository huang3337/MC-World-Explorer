# MC World Explorer V0.7.1 开发记录

- **版本定位**：V0.7 框架迁移的“工程与边界”里程碑
- **当前状态**：Task 5–15、Task 14 问题复审及真实存档只读验收已完成；开发者已确认 V0.7.1 里程碑完成，等待创建里程碑提交
- **目标分支**：`tauri-rewrite`

## 开发目标

- 建立干净的 Tauri 2、Vue 3、TypeScript、Vite 和 Rust 工程。
- 建立不依赖 Tauri 或前端的独立 `mcwe-core` crate。
- 建立最小类型化 Command、稳定错误 DTO 和前端错误显示。
- 建立任务标识、取消和过期结果隔离基础。
- 建立 Minecraft 来源路径的严格只读抽象。
- 建立从 EXE 所在目录派生的便携数据路径。
- 使用最小 Tauri capability，不引入 Shell、网络、文件系统写插件或 sidecar。
- 验证 `build --no-bundle` 生成的单个 EXE 可以在干净临时目录启动。
- 使正式上下文、路线、结构、规则和重大决策与新工程一致。

- 前端：Vue 3、TypeScript 和 Vite。
- 包管理器：npm。
- 三维：Three.js 与 WebGL 2，但 V0.7.1 不提前引入。
