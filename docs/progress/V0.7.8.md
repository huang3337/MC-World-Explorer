# V0.7.8 开发与验证记录

完成日期：2026-11-25。各节按验证日期与构建区分；现行源码状态、发布进展与下一步见[当前状态](CURRENT.md)，通用解析准入与失败语义见 [DECISION-024](../decisions/DECISION-024.md)。

## 开发目标

在 0.7.6（预扁平化区块解码、`FML.ItemData` / `FML.Registries` 数字 ID 还原、`DIM<整数>` 维度）与 0.7.7（`Level.Biomes` `byte[256]` 群系解码、`VanillaLegacyBiomes` 原版群系气候与水色表、`SavedBiomeColors` 缺失内置数据注册表回退）的基础上，补齐预扁平化两个世代（1.8–1.12.2 与 1.6.1–1.7.10）的只读三维纹理与模型解析链路，保持零字节码执行与未覆盖方块简化颜色底座降级边界。

## 实际完成

- **预扁平化客户端与实例资源归档准入（1.6.1–1.12.2）**：
  - `ClientResourceLocator` 支持为 1.6.1–1.12.2 及 `Anvil (<1.9)` 存档从所属实例目录（`<instance>/<instance>.jar` 或 `versions/<ver>/<ver>.jar`）自动匹配或手动绑定旧版客户端 JAR；未找到可用旧版客户端时回退简化颜色底座并给出说明，1.2–1.5 版本在自动查找与手动选包下统一按简化颜色底座提示。
  - `ClientResourceArchive` 新增 `ProtocolMode`（`MODERN`、`LEGACY_JSON_MODEL`、`LEGACY_FLAT_TEXTURE`），严格校验 1.8–1.12.2（`pack_format 1..3`，含 `blockstates/stone.json`、`models/block/stone.json`、`textures/blocks/stone.png`）与 1.6.1–1.7.10（无 `blockstates/`，含 `textures/blocks/stone.png`）两种旧版只读归档模式。
  - `ClientResourceArchive` 与 `InstanceResourceSource` 在旧版归档模式下对 `textures/blocks/*.png` 与 `textures/block/*.png` 执行双向受控解析，保持 1.13+ 严格路径语义不变；`InstanceResourceLocator` 支持受越界与重解析点校验约束的 `mods/<mcversion>/*.jar` 一级子目录扫描；`BuiltinResourcePacks` 与 `InstanceResourceSource` 只读解析 JSON 格式 `mcmod.info`（兼容数组根与 `modList` 对象根）提取 Mod ID 并标记 Forge 平台。
  - `ClientBlockColors`、`SavedBiomeColors`、`WeightedVariants`、`BlockModelResolver` 与 `SavedFluid` 扩展至 `pack_format 1..3` 与预扁平化 `data` 液量属性，使旧版客户端复用原版世界着色回退、`0..255` 维度高度、`VanillaLegacyBiomes` 气候水色表、旧式权重变体抽取、`multipart` 整组取反及流动水/熔岩坡面重构。
- **1.8–1.12.2 原版状态属性映射与 Forge Blockstate V1 解析**：
  - 新增 `LegacyJsonStateMapper`，将预扁平化扁平名与 `data` 映射至 1.8–1.12.2 `blockstates/*.json` 标识与变体属性（覆盖磨制花岗岩/闪长岩/安山岩、平滑砂岩/红砂岩、原木轴向、树苗生长阶段、楼梯/半砖方位与上下半砖、门、活板门、梯子、火把、栅栏、栅栏门、玻璃板/铁栏杆、红石线、铁轨、拉杆、按钮、压力板、中继器、比较器、草方块、灰化土、菌丝、海绵干湿、TNT、6 种双层植物、茜草花及 `silver_*` 浅灰染色方块等），兼容 `"normal"` 变体键、省略 `block/` 前缀的旧版模型引用及缺失 `blockstates` 的原版水/熔岩/空气/传送门内置几何回退。
  - 新增 `ForgeBlockstateV1`，声明式解析 `"forge_marker": 1` 的 `defaults.model`、`defaults.textures`、完整变体与单属性笛卡尔组合 `variants`、`submodel` 及 `x`/`y`/`uvlock` 变换；对依赖运行时代码的属性或未知自定义加载器保留原始方块身份并输出明确诊断原因。
- **1.6.1–1.7.10 内置静态几何与 `textures/blocks/*.png` 贴图合成**：
  - 新增 `LegacyFlatTextureModels`，在 `LEGACY_FLAT_TEXTURE` 模式下为原版常用方块提供纯静态几何与真实贴图映射：标准六面体（石头及变种、圆石、泥土、沙子、砂砾、矿石、矿物块、6 种木板、砖块、石砖、黑曜石、冰、雪块、萤石、地狱岩、灵魂沙、末地石、16 色羊毛 `wool_colored_*`、16 色染色黏土 `hardened_clay_stained_*`、16 色染色玻璃 `glass_*`）、多面异贴图方块（草方块 `grass_top` 群系染色与 `grass_side` / `grass_side_overlay` 叠合、灰化土、菌丝、6 种原木 `log_*` + `log_*_top`、砂岩、石英、工作台、熔炉、南瓜、西瓜、仙人掌、TNT、书架、干草块、耕地）、半砖、雪层与地毯、十字交叉植被（矮草、蕨、双层植物、花朵、树苗、甘蔗、枯死灌木、蘑菇、蜘蛛网）、6 种树叶 `leaves_*`（群系叶色）、睡莲、藤蔓、火把、梯子、铁轨及水/熔岩静态首帧贴图。
  - 对实例 Mod 中仅含单一同名 `assets/<ns>/textures/blocks/<path>.png` 且不存在 `_top` / `_bottom` / `_side` / `_front` 伴随贴图的简单方块提供受控六面体近似映射并附诊断说明；含多面伴随贴图、大写注册名或复杂渲染器的 Mod 方块保留原始身份、回退简化颜色底座并输出原因。
- **构建与缓存版本递增**：`build.gradle` 递增至 `0.7.8` 与 `build/core-0.7.8`，`tools/package-windows.ps1` 与 `VoxelPreviewCoordinator.RENDER_VERSION`（`v078-model-protocol-1`）同步更新。

## 遇到问题与审查修复

完成全部新增与修改文件的六维代码审查，修复并归档 6 项问题（4 项高、1 项中、1 项低）：

- **[ISSUE-BMODEL-032](../issues/resolved/V0.7.8/BlockModelResolver.java.md)**：1.8–1.12.2 原版归档不含 `water.json`、`lava.json`、`air.json` 等 `blockstates` 文件，补入 `LEGACY_JSON_MODEL` 下缺失对应 JSON 时的内置特殊几何回退与纹理来源登记。
- **[ISSUE-FLATMODEL-001](../issues/resolved/V0.7.8/LegacyFlatTextureModels.java.md)**：消除流体分支对 `BuiltinBlockModels` 的无保护强转，并在简单 Mod 单贴图判定中排除含 `_top` / `_bottom` / `_side` / `_front` 伴随贴图的多面方块。
- **[ISSUE-SAVEDFLUID-001](../issues/resolved/V0.7.8/SavedFluid.java.md)**：`SavedFluid.ownHeight` 在 `level` 缺失时回退读取预扁平化 `data` 属性，恢复 1.6.1–1.12.2 流动水与熔岩（`data = 1..7`）的液面高度差与流向纹理切换。
- **[ISSUE-LEGACYMAP-001](../issues/resolved/V0.7.8/LegacyJsonStateMapper.java.md)**：补齐磨制花岗岩/闪长岩/安山岩、平滑砂岩、6 种双层植物、树苗 `stage`、灰化土/菌丝 `snowy`、海绵 `wet`、TNT `explode` 与茜草花的 1.8–1.12.2 原版文件名及属性映射。
- **[ISSUE-IRLOC-005](../issues/resolved/V0.7.8/InstanceResourceLocator.java.md)**：`mods/<mcversion>` 子目录扫描补充符号链接/`isOther` 排除与 `toRealPath().startsWith(realMods)` 越界防护。
- **[ISSUE-CLIENTLOC-001](../issues/resolved/V0.7.8/ClientResourceLocator.java.md)**：`isValidVersion` 排除 1.2–1.5 版本，统一自动查找与界面手动选包的状态提示。

## 未完成内容与已知限制

- 已完成本机 1.7.10 实例的自动化只读纹理场景校验，尚未执行真实 1.8–1.12.2 客户端样本实测、原生三维窗口人工交互验收，也未创建 `v0.7.8` 标签或 Windows 便携发行包。
- 1.6.1–1.7.10 平面纹理模式仅覆盖常见原版静态几何与无伴随方向贴图的单一同名简单 Mod 方块；原版复杂异形方块（如楼梯、栅栏连接、箱体）与依赖 `ISimpleBlockRenderingHandler` 等运行时渲染器的 Mod 方块保持简化颜色底座并输出诊断说明。
- 1.8–1.12.2 模式下，依赖 Mod 运行时 `Block.getStateFromMeta` 推算的 `forge_marker: 1` 多值属性不通过执行字节码恢复，保留明确诊断并回退简化颜色。
- 1.6 之前（使用 `terrain.png` 整张地形图集的 1.2.1–1.5.2）存档继续使用三维简化颜色底座。
