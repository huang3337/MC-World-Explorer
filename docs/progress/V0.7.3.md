## 目标

在实际预览任务中自动使用存档所属实例的 Mod/资源包资源，让标准模型无需按方块登记即可显示；对仍失败的方块给出按出现次数归类的真实原因，再扩展能复用的模型表达/加载器。以“实例资源可用、标准模型正确、缺失/未支持可诊断、常见声明式格式可复用”为完成目标，不以几项夹具通过或某个 Mod 名称列入清单代替完成。

## 资源与范围约束

不将客户端严格版本校验放宽成任意 JAR。原版仍由 ClientResourceArchive 校验，Mod/资源包由独立只读源读取。只索引来源/namespace/条目存在性，实际 JSON/PNG/OBJ/MTL 按选区读取；所有归档/文件使用受控相对路径，禁止解压或执行类、脚本、Mod。最多 1024 个 Mod 归档候选，来源/索引/总读取/解码/图集预算独立有界，超量明确诊断，不能套用既有 16 层接口限制作为 Mod 数量限制。

以世界到最近 saves 的结构确定实例；不能仅从共享原版 JAR 猜另一整合包。手动选择只绑定当前世界/版本。启用资源包读取 options.txt 中的有界列表，先后顺序纳入身份；未启用包不加载，无法解析的 pack ID 明确说明。

本期不承诺任意 Mod Java BakedModel/BER 的动态形体、连接贴图运行时代码、动画和联网资源均可静态还原；不启用游戏导出桥接。若后续需要这些能力，单列证据与重大决策，不暗中执行。

## 验证计划及证据口径

本地样本包含“你好，新蒸程V1.5.9”的 1.21.1 NeoForge Mod 归档，Chipped 等作为格式样本，不作为支持白名单。不改动原游戏目录、options 或存档。运行报告/截图/测量/临时脚本保存在已忽略 build/ui-v073/；正式文档为本文件、决策及逐文件审查。

验收必须区分：静态标准几何、声明式 loader、明确缺资源/非法/超限、无静态几何/需运行时类型。纯资源准备成功不能冒充原生视觉或全 Mod 兼容；样本批次不等于全部运行时状态。

## 实施与门禁证据（2026-10-26）

### M1 / M2：实例资源进入真实预览

增加 InstanceResourceLocator / InstanceResourceSource，世界 resources.zip → options.txt 实际启用资源包（后启用优先）→ 当前实例 Mod JAR → 严格校验版本的原版客户端。ZIP与目录包均只读；不自动启用 resourcepacks 中的未选包，不扫描兄弟整合包。实例无法自动定位时支持手动目录绑定，按 world+version 持久保存，恢复自动只清该绑定。

UI 沿用已认可的三维工具栏、白色菜单与帮助气泡：增加“选择资源实例目录”“恢复实例自动定位”“查看资源诊断”。诊断按 TEXTURE_FALLBACK 的实际 occurrences 分类/排序，并展示实例、来源警告、最多128个实际读取引用和静态近似；不把资源警告次数当方块降级数。世界切换/绑定恢复、保存隔离、诊断数值及900×600 / 150%缩放菜单与气泡均有专项验证。

来源身份含路径/内容SHA-256/覆盖顺序。协调器真正使用组合来源；完整列表、启用顺序、目录新增/更改、已选坏来源变化都在请求/缓存边界检查。不同实例的缓存身份分别验证，不再互相清除。后台索引有进度/取消，未在FX线程读取大型Mod内容。

来源最多1024 Mod候选、单归档512MiB、来源总8GiB、总索引200万条/名称6400万字符、单包10万条、打开ZIP句柄LRU16；组合会话读取64MiB，单项类型另有预算。来源变化/关闭/总会话耗尽继续终止任务，单项资源超限只降级相关方块。

### M3 / M4：按表达复用的解析

- 标准模型父继承、textures引用、组合children/visibility合并；credit / format_version / Comment / ambient_occlusion等不影响静态形体的元信息兼容；未知几何语义继续明确拒绝。
- 不再提前解析所有未引用纹理变量；实际几何/材质所用变量仍检查缺失和循环。multipart基本值条件与palette属性匹配；随机模型仍固定首项并说明。
- 重复UV在图集局部格裁切，负值/多次重复不采到相邻图块；每面最多256格，裁切边界重复点去重。标准元素和variant旋转保留，**未实现root transform**，样本未发现该字段，不以忽略它伪造支持。
- 普通矩形PNG按完整宽高使用；有.png.mcmeta时按animation width/height/frames首项取静态帧。坏元数据/帧索引/尺寸可诊断，不靠长宽猜动画。同面覆盖层不同分辨率按归一化UV最近邻对齐，合成尺寸计入工作预算。
- 已分发 forge/neoforge/porting_lib 的 obj、composite、elements、empty、separate_transforms；world选择base，不执行item视角变换；支持 framework:open_model 的components静态元素。已知跨平台同格式loader声明可并存，其他冲突仍失败。组合默认材质传递至未覆盖的子部件。
- OBJ/MTL只读资源ID：v/vt/vn索引、负索引、三角/四边/凸多边形、flip_v、MTL相对引用/override、map_Kd资源变量、Kd/透明度和静态几何；不逐方块补材质。顶点65536、面8192、组合8192面，原始文件4MiB有界。

OBJ使用平面法线、保留面、方向光；未还原平滑法线/镜面环境效果/运行时部件变化。OBJ uvlock、线图元、凹多边形、带参数map_Kd、未知loader等明确未支持。不是运行Minecraft，也不是把Mod类装入程序。

官方格式参考：[NeoForge Custom Model Loaders](https://docs.neoforged.net/docs/1.21.1/resources/client/models/modelloaders/)、[Fabric Custom Models](https://wiki.fabricmc.net/tutorial:custom_model)、[Athena Loader Introduction](https://wiki.terrarium.earth/athena/loader-introduction)。Athena有专门连接语义，当前未将其静默当普通模型忽略。

### M5：真实样本与证据边界

本地只读样本有264个外层Mod JAR / 717780401字节；实际启用ZIP/目录资源另计。模型格式调查读取38837个block模型JSON / 32026469字节，4个未能按标准JSON解析；发现1141个neoforge:obj声明、12个composite和12个framework:open_model。调查是文件声明数，非实际世界方块出现次数，父继承会让实际使用状态数与声明数不同。

实际世界game取存盘玩家位置周围3×3主世界区块，目标X=-60..-58 / Z=63..65，包含halo成功读25区块。目标53种状态 / 468129个非空气方块；仅原版来源时1705个Mod方块降级，使用实例资源后该选区降级0、空几何0，成功包括4个Mod namespace，网格7141面。一次资源准备约275ms、网格约1801ms、整体约4048ms，仅为该轮单次测量，不代表所有选区或冷启动性能。

原生截图包括真实三轴Create轮OBJ、display_link组合、casing以及矩形纹理家具静态部件；标准/特殊类型旧场景也复测。每类30次图集上传/绘制/替换与最终关闭释放、GL错误/深度写入恢复检查通过。另一次各15秒隐藏960×720帧缓冲测量，Mod/标准/特殊样本p95分别0.058/0.059/0.044ms；这不是交互FPS或真实大型世界帧率承诺。截图已目视检查，完整交互/动态Mod外观仍需开发者体验。

全声明审计按每个外层Mod唯一blockstate ID选择一个代表状态，分批32、读取会话耗尽重开且核对相同指纹。它不覆盖所有属性、NBT、运行时连接和Mod载入代码；“无静态面”单列，不能计入可见成功。最终数量/回归与只读校验在下方补齐。

### 审查与剩余边界

本轮33个生产/测试/FXML/构建文件已按六维检查，记录11项中等问题及修复，无未解决高/严重问题；总索引124问题/55前缀。问题包括具体条目索引/句柄反复打开、启用配置原子收集/有界读取、跨世界缓存剔除、未引用变量、等价loader/基本值条件/组合材质、矩形与动画区分、UV边界、单项错误隔离和覆盖层分辨率。定向/整体结果以最终XML为准。

明确边界：外层Mod JAR与已启用ZIP/目录包，不自动解释嵌套JAR、启动器libraries中隐藏的资源、Mod代码注册的内置pack、资源包overlays或运行时合并包；未知pack ID有警告。重名Mod素材按稳定文件名顺序，可能与游戏依赖装载覆盖顺序不同，诊断显示说明。目录自动定位依赖最近saves结构，其他布局可手动指定。

Athena CTM、IE split/动态多块结构/自定义callback、邻域连接、动态/代码生成形体、未知color等语义不以静态空模型/整块冒充成功；仍降级或明确标记无静态几何。实际不存在的纹理/模型继续报告缺资源。复杂透明排序、流体/生物群系染色及特殊族原有静态近似保持。后续应据用户实际选区诊断排序，不能据本期样本声称所有Mod兼容。
