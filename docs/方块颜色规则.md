# 方块颜色规则

- **适用版本**：V0.6.0
- **源码基线**：`d58ddfca0119a9c9cb7e9a0f7e8f2fc623617866`
- **规则来源**：`BlockClassifier`、`BlockColorPalette`、`ChunkMesher`
- **用途**：记录首个正式三维版本的实际方块分类和简化颜色，供后续逐项优化与回归检查

## 1. 重要概念

程序对方块的处理分为三个步骤，不能把它们混为一谈：

1. **存档解析**：从区块 Palette 读取完整方块 ID 和属性。
2. **三维分类**：决定方块属于空气、不透明、镂空、半透明、流体或降级层。
3. **颜色解析**：为简化几何选择显示颜色。

荧光紫方块通常表示程序已经成功读取方块 ID，但没有对应的三维分类规则。它不表示 Region、NBT 或 Palette 解析失败。

## 2. 三维分类优先级

规则严格按下表从上到下执行，命中后不再继续检查：

| 优先级 | 判定条件 | 内部分类 | 渲染层 | 透明度 | 处理结果 |
|---:|---|---|---|---:|---|
| 1 | ID 位于空气表 | `AIR` | 无 | 0% | 不生成几何 |
| 2 | ID 为原版水或熔岩 | `FLUID` | `FLUID` | 72% | 仅生成直接暴露于空气的表面 |
| 3 | ID 位于半透明表 | `TRANSLUCENT` | `TRANSLUCENT` | 52% | 生成简化半透明方块几何 |
| 4 | ID 位于镂空表 | `CUTOUT` | `CUTOUT` | 100% | 生成简化镂空类方块几何 |
| 5 | ID 以 `minecraft:` 开头 | `OPAQUE` | `OPAQUE` | 100% | 作为普通原版不透明方块 |
| 6 | 其他命名空间 | `FALLBACK` | `FALLBACK` | 100% | 使用 `#E83EED` 荧光紫不透明立方体 |

当前版本不会根据 Mod 方块名称中的 `water`、`glass`、`leaves` 等片段猜测三维分类。例如 `example:clear_water` 和 `example:red_stained_glass` 均进入 `FALLBACK`。

## 5. 原版哈希颜色

未命中颜色片段的 `minecraft:` 方块仍属于 `OPAQUE`，并根据完整方块 ID 生成稳定颜色：

- 色相：Java `String.hashCode()` 对 360 取非负模。
- 饱和度：28% 至 45%。
- 亮度：52% 至 69%。
- 同一个完整 ID 在不同运行中保持相同颜色。

哈希颜色只表示“没有命中固定颜色规则”，不表示方块 ID 解析失败。不同 ID 可能得到相近颜色。

## 6. 非原版降级规则

| 判定条件 | 分类 | 渲染层 | 最终颜色 | 透明度 | 诊断信息 |
|---|---|---|---|---:|---|
| 未命中前述精确分类，且 ID 不以 `minecraft:` 开头 | `FALLBACK` | `FALLBACK` | `#E83EED` | 100% | 按完整方块 ID 聚合 `FALLBACK_BLOCK` 警告和出现次数 |

降级方块具有以下含义：

- 方块 ID 和属性已经从存档成功读取并保留。
- 程序不知道其正确的透明性、流体性质、模型或材质。
- 当前以醒目的完整不透明立方体显示，避免静默消失或被误认为已经准确适配。
- 即使名称包含 `water`、`glass`、`leaves` 等片段，也不会猜测三维分类。

## 7. 紫色的区别

| 外观 | 典型颜色 | 含义 |
|---|---|---|
| 鲜艳荧光紫 | `#E83EED` | 非原版命名空间的三维降级方块 |
| 较暗紫色 | `#8C5A9E` | ID 命中 `purple` 或 `magenta` 固定颜色规则 |
| 其他紫色或紫红色 | 不固定 | 原版 ID 的稳定哈希颜色，或者明确登记方块的当前哈希结果 |

V0.6 界面暂不显示降级方块 ID 列表。需要针对常见方块适配时，应以完整命名空间 ID 建立显式分类，并补充颜色、透明度、几何行为和测试，不能只根据名称片段推测其实际类型。
