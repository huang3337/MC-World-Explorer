# 未解析内容诊断

先记录原始方块 ID、状态、所选资源来源与具体失败原因。区分资源缺失、未知 loader、颜色回调未绑定、预算限制、坏资源和有意空模型，不用替代外观反推原身份。

在“资源与插件 → 解析诊断”按 Mod/命名空间筛选，查看方块详情中的原因码、loader 与资产来源，可导出本次完整 JSON。次数是问题出现次数，不是唯一方块数；截断时缩小选区重试。未确认归属不猜测，未采样内容不计通过。第三方实现前先核对 [插件开发说明](PLUGIN_DEVELOPMENT.md) 的适用边界和当前 core.1 接口。

0.7.4 只处理有证据、可复用的本体缺陷；固定样本与第二独立来源足够验证时不再扩扫全部 Mod。专用注册、生成几何、运行时颜色和容器布局均不属于本期支持，见 [DECISION-024](decisions/DECISION-024.md)。
