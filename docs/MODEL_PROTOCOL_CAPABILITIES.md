# 0.7.4 资源解析范围

当前构建为零预装插件的本体，具备通用插件安装、启停、卸载和隔离执行能力；不包含 SDK 分发与专用 Mod 适配。准入与失败语义见 [DECISION-024](decisions/DECISION-024.md)，状态见 [V0.7.4](progress/V0.7.4.md)。

标准 blockstate/JSON、父链、纹理、普通几何与普通 OBJ 由本体解析。加载器格式差异只在已有证据的版本范围内处理；未知 loader、运行时生成模型及未知颜色处理器保留原始方块身份与明确原因。空声明与缺资源不能混为成功。

| 本体内容 | 准入依据与边界 |
|---|---|
| 标准 blockstate 与 JSON 模型 | variants/multipart、父链、纹理引用、elements、UV/变换、材质；未知渲染字段明确拒绝 |
| 普通 OBJ | 同一读取器通过 Create 与 Immersive Engineering 的独立真实资源见证，不保留专用私有回调 |
| 标准颜色 | 已选原版客户端的有限绑定与草/叶/水群系语义；未知 Mod 回调保留诊断 |
| 来源与预算 | 所选实例与客户端、资源包顺序、完整 SHA、输入变更检测和有界缓存 |

当前标准颜色协议证明限定于 1.20.1/1.21.1 对应客户端构建；实际输入不匹配时明确降级。Mod 归属来自已选实例的唯一元数据身份，资源来源单独显示，不从材质或外形猜测。

通用不表示全覆盖。当前固定选集、自动回归与原生人工验收分别记录；不承诺整个 Mod、全部资源包或未来版本兼容。

外部插件安装后默认停用；只接受当前 `mcwe-model-api-1-core.1` 接口清单。此前专用协议探索的 preview 清单不兼容，会在执行前拒绝；本轮不迁移这些插件。隔离 worker 负责可终止的生命周期，不是操作系统权限沙箱，卸载清理限于宿主管理副本、索引、进程和缓存，不擅自删除原始安装文件或无关用户文件。
