# 本体标准颜色协议证明

1.20.1、1.21.1 的证明供 `ClientBlockSymbols` 和 `ClientBlockColors` 读取静态方块注册。1.21.5、26.1、26.3 的 [vanilla-tint-layers.json](vanilla-tint-layers.json) 记录已核实的原版世界着色语义。客户端整包 SHA-256 匹配时直接采用声明。重新打包的客户端需逐项匹配所列类的 SHA-256。

`groups` 声明适用方块和从索引 0 开始的有序颜色来源。每份客户端证明列出已核实的组。1.21.5 的注册回调用最后一项描述后续非负索引，花簇的索引 0 为白色，后续索引取世界草色。26.3 的有序来源仅声明已核实的索引。模型中未带索引的面直接使用纹理。未知方块、来源或指纹在使用未绑定索引时产生诊断。

实体模型、Mod/加载器注册探索及插件协议证明已分离到本期工作树之外，不进入应用资源。

`compatibleBuilds` 记录共用注册入口及图层表的构建证据和采样精度差异。铜傀儡雕像的 [关节数据](copper-golem-statue.json) 由本地客户端四个静态姿态的部件和方盒定义核对。
